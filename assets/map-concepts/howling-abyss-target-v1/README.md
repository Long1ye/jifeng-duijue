# 嚎哭深渊纯地图美术目标 v1

这组图是由game-assets / Meowa通用生成制作的美术目标候选，不是当前游戏截图，也不是已经切分、无缝或可直接上游戏的资源图集。

四张图均已生成并检查：2048×1152、不透明PNG、无裁切或重采样。净消耗46积分；首个出生区任务失败退回12积分，重试成功。用户已认可出生区与中央桥段方向；外塔因像纪念碑而退回，应改为更明确的战斗防御塔。尚未冻结生产规范，也未通过游戏实机验收。

| 图像 | 用途 |
| --- | --- |
| [01-overview.png](01-overview.png) | 出生区至中央桥段的连续环境氛围与空间层次 |
| [02-sanctuary.png](02-sanctuary.png) | 蓝方出生区、晶体祭台与庇护平台 |
| [03-outer-tower.png](03-outer-tower.png) | 外塔雕塑语言、基座与道路接合 |
| [04-central-bridge.png](04-central-bridge.png) | 中央刻纹、开阔战斗面、冰雪过渡和桥体纵深 |

四张图采用共用总览参考，保持冷灰石材、深蓝冰隙、暖色小火盆和风积雪的视觉关系。它们是相关区域的独立目标构图，不能拼接成精确连续地图；比例、遮挡、碰撞和摄像机仍需要结合实际游戏校准。未建立严格的像素网格、图集切块或可复用模块契约，不能直接缩小整图当作像素生产资产。

原始生成输出、声明的final_outputs保留于`assets/ha-target-a`、`assets/ha-target-b2`、`assets/ha-target-c`、`assets/ha-target-d`。首次出生区任务位于`assets/ha-target-b`，服务返回model_call_failed并退回12积分；该目录仅保留失败清单，不含可采用图像。随后简化描述独立重试，没有重复提交仍在运行的任务。本目录PNG为原图逐字节复制，无裁切、缩放或修图；`manifest.json`记录任务来源、实际尺寸与SHA256。可用`python scripts/package-howling-art-target.py`重建。

先审阅目标图，再从采用部分提取地表、雪冰过渡、栏墙、支撑、塔体、雕像和装饰的制作契约；不自动把所有细节判为已采用，也不启动全图量产。
