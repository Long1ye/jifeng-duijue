# 嚎哭深渊式单路地图：结构稿 V1

本版本是可编辑的关卡轮廓，不是最终地图美术，也未替换主游戏。

参考 Riot 官方 Howling Abyss 介绍中的单桥、双端基地与桥侧草丛结构：
https://www.leagueoflegends.com/en-us/news/game-updates/aram-2023-preview/

该文章属于历史版本资料；本稿没有采用其中的倒塔残骸机制，也不声称复刻当前版本精确点位。

## 编辑约定

- `layout.json` 是唯一布局来源；u 沿桥轴，v 横跨桥面，单位是本项目单位，不是 LOL 单位。
- 红方由蓝方点位绕中心旋转 180° 得到，避免两侧手动维护失配。
- `geometry.ts` 定义桥面轮廓、宽度插值、投影与可通行几何查询。
- `preview.ts` 只画占位图形；桥宽、图层显示和导出可在页面操作。
- 点击角色标记用于空间检查，不表示已接入人物移动、塔碰撞或战斗。
- 草丛与水晶已接入独立透明像素素材（v2 草丛加密加高、水晶改宽底座），塔有独立美术；其余未完成的物件槽继续保留 null。草丛隐身与水晶血量仍未实现。
- 草丛布局为五处：四处沿桥的一侧，分布在两侧塔间与中央接战区；一处在中央另一侧。它参考 Riot 2023 年对桥下侧新增草丛、加宽塔间草丛的设计说明，但不是原版坐标测绘。独立引擎图层仅做轻微摆动，不提供隐身规则。

## 后续填充顺序

1. 先确认桥宽、基地长度和外塔间距。
2. 用 game-assets 生成冰石桥面、桥沿、桥墩等独立可拼接素材。
3. 生成防御塔、水晶、基地和草丛；以配置坐标为脚底锚点。
4. 将地面、障碍、实体、前景、环境动态分别接入 Phaser；碰撞与图像尺寸独立。
5. 最后加落雪、深渊雾与冰晶微光，避免氛围遮住技能和兵线。

美术资源生成留到后续阶段，本轮没有提交新的付费生成任务。
