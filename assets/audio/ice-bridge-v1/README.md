# 冰桥环境音 v1

按用户要求，应用默认关闭这一组生成的风声、火盆声和冰裂声，关闭时不加载或播放。官方地图 BGM 和英雄音效仍保持开启；需要时可通过“环境声音”单独恢复。

使用项目 game-assets Skill 的音效生成：8 秒寒风循环、6 秒火盆循环，以及雪地脚步、石面脚步、远处冰裂各 2 秒。按用户反馈移除脚步声，运行时仅引用 wind、fire、ice-crack 三个 MP3；脚步源文件保留但不加载、不打包。

`audio-validation.json` 记录了实际解码时长、峰值与 RMS。五段均解码成功，无样本峰值超过 1；火盆为低平均响度、偶发爆裂的音轨。此项是定量检查，不代表已经完成音色、响度搭配或循环衔接的听觉验收。

运行时对循环首尾做 0.22 秒交叠混合，避免硬接缝；原音频文件保留不改。现有“音效”总开关默认关闭，用户开启后才解锁 AudioContext 并加载素材。“环境声音”可单独关闭。暂停、结束、隐藏页面或关闭声音时停止并断开环境声音节点，重新开始复用解码后的缓存。异步加载完成不会绕过静音状态启动声音。

声音以镜头中心为听音位置：火盆使用最近三个音源、距离衰减和左右声像；风强度跟随共享风场与桥缘距离；冰裂以 26–45 秒左右间隔出现。交战时略微压低环境声。非循环声音最多同时 8 个。不播放脚步声；视觉脚印不受影响。
