Q 的两个版本交替使用，停止音效或重置靶场不重置轮换次序；Q3／EQ3 使用新增视频的音轨，不占用普通 Q 轮换。Q3、R 文件从 MP4 中提取 AAC 音轨后转 MP3。普通 Q／EQ、Q3／EQ3 和 R 命中时不再叠加此前的演示命中片段，避免重复人声或接触声。

Q-v1 裁取 0.19–0.62 秒，Q-v2 裁取 0.015–0.585 秒，R 裁取 0.86–2.48 秒，去除前后空白或低音量底噪；配平响度并加短淡入淡出，不改变音高。源 Q-v1 解码峰值略超 1，运行副本已降低增益，三段运行音频均实际解码并确认非静音、峰值小于 1。

新增 Q3 裁取 0–1.23 秒，保留主要动作声音、去掉尾部低音量底噪，配平响度并加短淡入淡出。四个源文件哈希均保持不变；Q3／EQ3 路由和旧片段排除验证通过，全量 500 项测试及构建通过。

复现处理：`python scripts/import-yasuo-user-audio.py`。所有路径从脚本位置解析，不依赖终端工作目录，不会把输出写到项目同级目录。

验证：普通 Q 轮换、R 使用用户音频、命中不重复播放及静音节点回收测试通过；浏览器开启音效后连续试放 Q 与 R，未记录控制台错误。截图位于 `docs/visual-validation/2026-10-15/user-yasuo-audio-trial.png`。此项不代替实际听感验收。

## 赶路音频（2026-10-15）

两个 MP4 分别提取 0–3.65 秒、0.05–5.00 秒，去掉尾部低音量空白，配平音量并加短淡入淡出。按角色持续实际位移触发，不按移动点击次数触发：连续移动至少 2 秒、累计位移至少 35，距离任意存活敌方单位至少 260，脱战超过 5 秒。两段交替播放，触发间隔 16–19 秒，音量为战斗采样的 80%；播放期间 BGM 自动降低。

攻击、施法、受击、敌人接近、暂停、切到后台、死亡或关闭音效时停止赶路音频；普通停步允许当前片段自然结束，站立时不会触发新片段。仍不添加循环脚步声。导入共六段音频，源文件保持不变；赶路调度、战斗打断、片段轮换和节点回收已测试，全量 507 项测试及生产构建通过。音量与内容衔接仍以实际试玩听感为准。

## 吹箫（Ctrl+3）

新增 `亚索吹箫音效.mp4`，提取 0–6.3 秒音轨到 `runtime/yasuo-flute-user.mp3`，按现有管线配平音量、添加短淡入淡出。Ctrl+3 与动画同时触发，不叠加赶路语音；音频未加载完成时按动画已播放的时间偏移开始，不从头错位播放。播放期间降低 BGM，动作取消或暂停时停止，继续比赛时从动画当前位置恢复。所有七个源音频文件哈希保持不变。

快捷键兼容：部分浏览器或应用会在页面收到按键之前用 Ctrl+3 切换标签页，此时页面无法阻止。游戏支持单按 3（含小键盘 3）和“选项 / 练习”中的“吹箫 · 3”按钮作为可用入口；转发到页面的 Ctrl+3 会在捕获阶段处理。暂停或未开局时会显示提示。

吹箫现持续循环，直到移动、攻击、施法、S 停止或受击取消；音轨使用单个循环音源，不逐帧重建。暂停后恢复、静音后再开启或音频延迟加载时，按累计动作时间对音轨时长取余恢复循环位置。
