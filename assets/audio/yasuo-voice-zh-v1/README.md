# 亚索基础皮肤完整中文语音

来源为用户提供的本机 `D:/Long1ye/英雄联盟(26)/Game/DATA/FINAL/Champions/Yasuo.zh_CN.wad.client`。仅只读提取，未修改客户端。并非合成、配音克隆或从网络另找的录音。本包范围为基础皮肤，不包含另有表演及台词的其他皮肤语音。

通过 BKHD bank id 与 Wwise FNV 名称散列识别 `yasuo_base_vo_events` / `yasuo_base_vo_audio`；音频实际为同一归档中的 WPK 流媒体。`source.json` 保存客户端 SHA256、归档项散列及事件声明；用原 `skin0.bin` 事件名解析，包含 29 个可播放事件入口。部分普通/暴击攻击入口共用同一组 4 个声音，不重复复制媒体。

`manifest.json` 中 91 条独立媒体覆盖事件 bank 全部 91 个 sourceID，missing 为 0；完整时长约 314.29 秒。保留每条原始完整内容，没有裁短台词。运行时转换为 44.1kHz 单声道 96kbps MP3，共约 3.85MB；每条基于峰值和 RMS 调整增益，保留余量。浏览器逐条解码验证输出，无空音或削波。

技能音效保留既有原版 SFX；正常游戏的 Q/R 停用旧的混合喊声录音，避免与新 VO 双重说话。旧录音文件及原有独立试听未删除。
