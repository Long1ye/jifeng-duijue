# EQ3 multilayer ring — visual draft

Generated by game-assets animated-frame editing from the approved independent EQ ring. A second edit attempted to tighten the layer spacing but did not resolve clipping. Keep both generation results for traceability; the preview uses refined/media.

176×144 RGBA, eight 100ms frames. Three elevated wind rings, independent of the existing eight-direction E character sprites. Preview retains the ordinary EQ timeline and rear/body/front composition, and supports hiding the body or comparing the ordinary EQ effect.

Known issues: top ring touches the canvas top in frames 3–5; frames 1–2 contain stray bottom-edge pixels. Preview displays only active frames 3–6, so the stray lead frames are not shown. Final asset needs further art cleanup before production. No main-game replacement or gameplay changes.
