# 精简像素 HUD · 已接入游戏

使用项目 game-assets 技能的 Meowa UI 生成流程，参考实机裁切与既有 R 就绪图标绘制。八个新图标为：亚索头像、被动、Q、W、E、R、D、F。计划见 plan.json；生成成品与官方输出清单保存在 generated/，运行图标与裁切坐标见 assets.json。复现裁切：`python scripts/package-pixel-hud.py`。

保留每个图标原始像素，不二次像素化。原图间隙包含背景，运行素材按已验证矩形分离，图标本身为不透明暗色方形。边框与布局使用 CSS 硬边、阶梯切角；实时数字、血蓝条、冷却遮罩由现有 HUD 更新。生命/法力使用当前游戏规则，不复制参考截图中的固定数字。

已替换 src/ui/LeagueHud.ts，引入 pixel-hud.css。底部保留头像、单个被动图标、QWER、生命/法力和 D/F 双槽；无等级、装备、金币、侧边功能或升级提示。R 默认彩色，真实冷却时覆盖遮罩，击飞接大提示继续使用原有判定。被动仅图标，未新增未实现的护盾数值。D/F 目前没有游戏机制，明确显示为不可用，并有辅助说明。吹箫、停止和属性信息位于选项菜单，原快捷键保留。小地图为右下角方形界面，点击坐标保持一致。

浏览器检查：八张图全部加载；点击 Q 后法力减少、出现冷却；R 默认无冷却遮罩；菜单仍可使用。所有导出图标实际解码、尺寸与原图裁切逐像素核对通过，生产构建通过。游戏效果截图：gameplay-preview.png。
