# 蓄风、闪现与点燃

使用项目 game-assets skill 的通用生成制作，原任务 `job_b304fdde1444431fbf826335076de92d`。生成图是原创像素风演绎，并非客户端提取素材。

`generated-sheet.png` 保留最终原图；`runtime/vfx-atlas.png` 分为 4 列、4 行，每格 256×320，无缩放。行依次为蓄风后层、蓄风前层、闪现四阶段、点燃循环。切片与透明边缘检查记录在 `contract.json`；`contact-sheet.png` 是深底接触表；`index.html` 可播放完整循环。

Q3 前后层以角色脚底为锚点，状态消耗、过期或死亡后隐藏。游戏逻辑时间驱动帧与上升细丝，暂停时冻结。D 闪现播放起终点双爆闪，F 点燃跟随目标并在目标死亡时消失。

本版同时接入可试用的 D/F：闪现距离 140、冷却 300 秒；点燃距离 160、5 秒内分 5 次共 100 点真实伤害、冷却 180 秒。点燃伤害是当前无等级系统的原型固定值，不表示官方满级伤害；尚未实现重伤和召唤师技能音效。练习模式提供预览蓄风、试放闪现和试放点燃按钮。
