# 浪客之道 · 动画护盾

使用项目 game-assets skill，通用生成银白风盾首帧，再通过 Frame Animation HD 路线生成八帧透明循环。原创像素风效果，不是客户端提取。

首帧任务 `job_9ba520fa900d4eb1a1e87353e2843a67`，动画任务 `job_f663be2813aa4d2586a6b1eb624e6456`。`generated/` 保留所有最终媒体；`runtime/` 是统一包围盒的八帧与 atlas，未缩放原帧。`contract.json` 记录实际尺寸和透明边界。

运行时前后分层环绕角色，留空躯干，触盾时快速聚拢；真实护盾破裂时播放短消散，正常到期前淡出。全部受模拟时钟驱动，暂停和慢放与护盾判定同步，死亡和重开立即清理。血条上方的白色护盾量条及旧静态双椭圆已移除。护盾数值、触发与吸收规则未改动。

`index.html` 可播放完整周期，也可测试立即破盾。
