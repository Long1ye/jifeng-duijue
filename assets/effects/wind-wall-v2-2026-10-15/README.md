# 亚索流风之墙 V2

通过项目 game-assets skill 创建：通用生成风墙首帧，再使用 Frame Animation 的 HD 路线制作八帧循环。HD 路线用于保留较大像素风素材的形状；结果不是官方客户端提取。

- 首帧任务：`job_ff36eb1a539041a7b293f01f7742d196`
- 动画任务：`job_e980a7f647c94486a6c4776371007f95`
- `generated/` 保留生成的最终媒体，包括 WebP 动画、透明 GIF 和透明原始帧表。
- `runtime/` 是八帧透明切片和统一包围盒的 4×2 atlas，未缩放原帧；`layout.json` 给出实际尺寸。
- `index.html` 使用游戏相同的绘制模块，可查看任意方向、升起、持续和消散。

新风墙始终是竖直风幕，地面方向随施法方向变化；侧视保留薄层厚度。持续时间仍为 3.9 秒，宽 128、高 64、厚 8，与原来拦截判定一致。动画使用模拟时间，因此暂停、慢放和重新开局均不依赖浏览器计时器。原风墙音效与阻挡规则保留。
