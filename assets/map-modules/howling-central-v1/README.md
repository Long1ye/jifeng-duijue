## 采用检查与限制

- 通用生成没有严格像素网格保证，部分透明资源含软晕和细腻边缘。候选运行材质以最近邻、AlphaTest抑制低透明外晕，最终锯齿/冰缘仍需实机观察，不宣称已达到规范化像素生产质量。
- 栏墙底部存在透明留白；运行UV按实体Alpha轮廓取范围以对齐脚底。桥拱原图混入上层栏墙，运行UV从y=205开始使用，避免重复栏墙。它们是UV取样，不修改原始PNG。
- 雪边取原图上部512px，避免大面积透明留白浪费地表跨度；连续三段交替水平镜像，降低边界高度跳变。仍只有一个雪边变体，没有宣称无重复或已具完整内外角过渡图集。
- 地表是唯一中央地标patch，限定区域使用，不宣称可无限无缝铺贴。该patch与旧地表的边界、栏目连续性、镜像母题以及素材在640内部宽度下的细节密度，均列入实机待验收。
- 火盆当前是静态像素图加轻微明度脉动，环境灯沿用模拟时钟；不是逐帧火焰动画。远景是独立平面，不是完整三维岩壁。

运行契约见`src/render-three/CentralBridgeLayout.ts`，实现为`CentralBridgeArt.ts`。本版本是P2首次目标图资源接入候选，不是全图资产冻结或美术验收通过。
