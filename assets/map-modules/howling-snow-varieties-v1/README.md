# 八种积雪运行素材

依据用户认可的八格概念图，使用内置 imagegen 制作一张透明图集。最终源图 [atlas.png](atlas.png) 为 1774×887 RGBA，alpha 范围 0～255，约 1.24 MB；[完整生成提示词](prompt.txt)与 [UV、锚点及高度清单](manifest.json)已保存。

按从左到右、从上到下排列：

1. 贴墙厚雪：三段起伏的纯雪包。
2. 碎石覆雪：散乱碎石和分离雪帽。
3. 风积雪脊：不对称流线雪脊。
4. 薄雪残片：雪片之间保留透明露地孔隙。
5. 柱脚拥雪：围绕透明中空位置的雪与小石。
6. 融雪边缘：保留中央透明空间的退缩雪环。
7. 草根积雪：两端及前缘的小雪包，中间透明。
8. 冻融雪壳：碎裂厚边雪壳与局部薄冰。

图集中没有墙、柱子、火盆、火焰或草丛实体，这些继续使用游戏的现有物件。所有类别共用一张纹理和两批绘制（雪体、接触影）。没有把概念板中的地砖或墙面直接贴入游戏。

`scripts/inspect-snow-varieties.py` 只读取 alpha 和检查过的透明分隔区域，输出元数据，不修改或重绘源像素。程序以完整 UV 区域选取各轮廓；没有切断雪包来伪造变体。运行时做固定 45° 浅浮雕、桥向校准和按类型限制高度，草根、薄雪和融雪压低纵深。不是可自由旋转的雪体模型。

接入：`SnowVarieties.ts`。原认可版覆石积雪保留在 `SnowBanks.ts`，通过 `setVariety(false)` 可在诊断时对照；正常游戏默认启用八种形态。全部受现有「冰雪景观」开关控制。
