# 建筑冰晶 v1

重新参考霜覆直墙概念图的小冰晶与新版围栏，使用内置 imagegen 生成四种建筑附着款：墙缝侧生晶体、墙顶晶簇、桥沿下垂晶体、柱脚包裹晶体。原图 atlas.png 保留；独立 PNG 仅裁切、保留原始 RGBA。左列两格按实测空白区划分，避免墙缝尾部进入下垂晶体文件。

提示词：透明 2×2 建筑冰晶图集，匹配蓝灰雪覆哥特桥、45 度正交相机、左上光照。四格依次为从细窄竖墙霜缝侧向生长的非对称晶体、根部扁平可落在压顶上的小冠状晶簇、从窄附着边向下生长的角状晶体、沿假想方柱脚两侧弯曲分布的低晶体。各格留透明间隔，不生成实际墙体、石地基、植物、地面板、背景或文字，冰蓝克制且无强发光光晕。

## 场景分布

ArchitecturalIce.ts 统一管理七种晶体形态，包括复用的三种地面款。撤掉旧 PaintedBridgeSample 中统一抬高 40 的大型带石底冰晶，以及 PaintedSmallDetails 中重复散放的地面冰晶。

- 地面：后侧墙脚几组主晶和碎晶，基地少量冰扇，避让草丛和火盆。
- 墙缝：接近实际柱位的细长冻结裂缝与侧生晶体。
- 墙顶：少量晶簇落在压顶雪面，根部下沉，避免浮在墙外。
- 柱脚：贴合两侧柱脚的弯曲晶簇；前侧利用外侧浅台沿落脚。
- 桥沿下方：前侧桥沿下唇的倒挂角晶，与普通白色冰挂区分。

控制尺寸、明度及留白，不作均匀撒点。每种材质合为一个静态网格，共七批；不改变碰撞或战斗。
