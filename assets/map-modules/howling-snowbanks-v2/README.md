# 积雪与碎石路肩素材

用于替代用户否定的程序染白雪斑。内置 imagegen 按用户提供的雪覆碎石局部图生成，已保存原始最终 PNG，未重绘或修改源像素。完整提示词见 [prompt.txt](prompt.txt)。

最终图片：[snow-rubble-bank.png](snow-rubble-bank.png)，1536×1024，RGBA。检查 alpha 范围 0～254，画布角落为透明，主要物件有约 32 万个 alpha≥240 像素。运行时 alphaTest 0.38 配合 MSAA 边缘覆盖，不显示透明区的背景 RGB。

接入：`SnowBanks.ts` 使用固定 45° 浅浮雕，限制实际雪石高度，维持源图投影；共享一张纹理合批雪包与接触影。位置避让已有草丛、火盆和中央兽柱；只占路肩，不参与游戏碰撞或拾取。使用原有环境灯光；暂停不产生独立动画。素材不是完整可旋转三维模型。
