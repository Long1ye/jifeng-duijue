# 中路 Solo 首版比赛规则

## 对局与胜负

单机玩家控制蓝方，AI 控制红方，双方使用同一个固定属性英雄。地图为一条中路，双方各一座防御塔。

满足下列任意条件即结束比赛：对手英雄死亡、对手防御塔被摧毁、己方补刀达到 100。英雄因防御塔或小兵伤害死亡同样判负。每个固定逻辑步统一收集胜利事件，同步判定；同一步双方同时达成条件则平局。同一步同一方达成多个条件时，结算原因依次优先一血、一塔、100 刀。

只有英雄对敌方小兵造成最后一击才计入补刀，普攻和技能使用同一计数规则。小兵击杀、防御塔击杀以及击杀英雄均不计入补刀。

## 战斗与防御塔

右键点地移动，右键敌方单位追踪并普攻，左键选择单位，S 停止行动。普攻有前摇和间隔；移动指令可取消未完成前摇，已经发出的弹道继续飞行。

防御塔优先攻击小兵，没有小兵时攻击英雄。敌方英雄在塔范围内攻击己方英雄时，防御塔转移仇恨至该英雄；目标离开范围或死亡后重新选目标。塔射击采用追踪弹道，离开塔范围不会销毁已发出的弹道。

英雄走回己方出生点附近可恢复生命和法力。英雄死亡直接结算，不包含重生或核心。

## 技能与比赛流程

Q 棱光箭为命中首个敌人的直线弹道；W 疾影步为鼠标方向短冲刺，短暂减伤；E 裂光阵在鼠标指定位置预警后造成范围伤害和减速。技能均消耗法力并有冷却。

首次点击开始进入比赛。暂停冻结逻辑时间，恢复后继续。结束后冻结出兵、AI、伤害和计数。重开新建比赛状态，清空单位、弹道、技能区域、计时与结算结果。
