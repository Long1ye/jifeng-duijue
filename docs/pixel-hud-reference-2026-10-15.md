# 实机参考像素 HUD

参考：`assets/source-materials/references/原版实机画面.mp4`（27.39 秒，1904×1024）。抽取 0、5、10 秒画面用于观察；截帧位于 `docs/visual-validation/2026-10-15/ui-reference/`。没有修改源视频。

沿用实机的信息区域：右上角对局数据、底部中央英雄操作区、右下角小地图。HUD 采用深蓝黑底板、双层硬边金属框、阶梯切角头像、像素采样图标、紧凑的 QWER 与血蓝条。保留本项目实际补刀目标，显示实时生命、法力、冷却与现有属性；不伪造装备、经济或升级系统。增加实际可用的 3 吹箫、S 停止按钮，原有选项菜单保留。

使用 DOM/CSS 与现有图标制作，保留已有元素 ID、技能事件与状态更新。小屏幕逐步收起属性和次要动作按钮，键盘快捷键仍可用。延续此前隐藏调试提示、建筑占位与远处防御塔提示的设置。

验证：生产构建通过；浏览器中检查 832×884 布局，点击 Q 后法力减少并出现冷却倒计时。截图：`docs/visual-validation/2026-10-15/pixel-gameplay-hud.png`。

## 全窗口游戏视图

画布根据窗口实际宽高调整渲染尺寸，镜头、鼠标映射、边缘滚动和小地图视野使用同一动态逻辑视口。HUD 叠加在地图上，不再使用固定 16:9 画布居中造成上下留白。浏览器实测画布与容器均为 (0,0,832,884)，右键移动正常；541 项测试及构建通过。效果：`docs/visual-validation/2026-10-15/full-window-game-hud.png`。
