# 交战区动态第一版

2026-10-19。用户明确要求可见运动，并认可贴地风卷雪、草丛阵风和偶发跨桥乌鸦三个方向。实现完成，视觉效果待用户确认。

[播放 16 秒连续实机预览](preview.html)。录像使用实际 ThreeArena 渲染，固定 45°、缩放 0.4；20 次/秒推进模拟，视频约 15.86 秒。这是环境动态展示，不是实战录像或性能帧率基准。约 11～15 秒中央乌鸦由远墙飞向近墙。

## 实现与回退

- `GroundSnow.ts`：8 个固定实例，一次绘制；每处周期 12 秒、活动 5 秒，错相出现。最高透明度 0.26，主路中央降低到 40% 权重。贴地、正常深度测试、不写深度，无新纹理或持续创建的粒子对象。
- `EnvironmentMotion.ts`、`PaintedDetails.ts`：复用共享阵风，草根固定、草梢增强摆动，不同位置错相。
- `MapRavens.ts`、`RavenBehavior.ts`：复用 3 只乌鸦和原图集，选择真实两侧墙头、避开兽柱；跨桥飞行 3.8 秒，起飞错相，不新增鸟。
- 动态跟随比赛时间，暂停冻结、重开复位。地面雪随「风雪层次」关闭，轻量档关闭；乌鸦沿用 `wildlifeEnabled`。未增加碰撞、选取或伤害对象。

## 验证

`node scripts/validate-combat-ambience.mjs` 输出 [report.json](report.json)、连续录像与浏览器视频播放截帧。视频已验证可解码、可定位播放，12 秒中央乌鸦为 flying 状态。

地面雪隔离检查：相同镜头 7.6→7.9 秒有 5755 个像素变化、最大通道差 19；冻结时间重复渲染差异为 0。此数据仅证明更新和暂停正确，不代替动态观感判断。该镜头绘制调用 81→82，五次重开均为 71 个几何体、29 张纹理，无控制台错误。天气开关、轻量档、暂停检查通过。

全量测试 154 文件 828 项通过；专项 4 文件 10 项通过；最终 `npm run build` 通过。`validate-three-combat.mjs` 检查技能、34 个音频文件、暂停及五次重开资源稳定，errors/failed 均为空，证据见 [combat](combat/)。

复现入口：`/three.html?map=howling&scene=central`。正常战斗的最终动感、强度和清晰度仍以试玩反馈为准。
