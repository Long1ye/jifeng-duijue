# 战争迷雾：草丛颜色修正

[查看正常比例对照](http://127.0.0.1:5173/docs/visual-validation/2026-10-19/war-fog-brush/comparison.html) · [进入比赛](http://127.0.0.1:5173/three.html?map=howling&scene=match)

问题：视觉迷雾曾直接采用草丛隐藏过滤，导致我方站在草外时，视野范围内草叶也变黑。

修正：`WarFog.ts` 的地表颜色仅依据共享视野半径和柔边；`TeamVision.ts` 继续独立处理草内敌人的隐藏。近处草丛保留原色，失去视野后自然压暗。没有修改草丛素材、敌人暴露规则或视野半径；移除草丛栅格缓存，无新增绘制和纹理。

实机验证使用中央草丛、1600×900、固定 45°、正常缩放 0.6。同一相机和模拟时间比较开启/关闭迷雾，64×64 草叶区域平均通道差 0.586/255；离开视野后，该区域亮度为关闭迷雾的 78.1%。参考截图 `brush-nearby.jpg`、`brush-original.jpg`、`brush-outside-sight.jpg`。中央草丛避开基地和友方塔的固定视野，确保离开后确实失去视野。

[浏览器报告](report.json)八项通过：远处敌人隐藏、友方小兵共享视野、失去视野隐藏本体与血条、暂停移镜头不揭图、草外敌人隐藏、近处草叶保色、视野外草叶变暗、进入同片草揭示敌人。浏览器错误为空；五次重开资源均为 65 个几何、34 张纹理，无递增。该资源值仅对应本次相机加载范围。

新增回归测试覆盖草丛被照亮但敌人隐藏、离开视野压暗、重新接近恢复原色。复现：`node scripts/validate-three-war-fog.mjs docs/visual-validation/2026-10-19/war-fog-brush`。正常比赛默认使用修正；旧版目录保留历史截图。
