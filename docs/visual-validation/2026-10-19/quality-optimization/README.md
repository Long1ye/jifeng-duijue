# 冰桥画质逐项优化验证

维护入口：[Three.js 画质优化与维护](../../../threejs-quality-roadmap.md)。本目录保存 2026-10-19 本轮证据；此前战斗迁移证据保持原样。

## 本轮交付

- 角色脚底接触影和外影分离，击飞时接触影先淡出，外影留在地面。
- 大建筑接地实例化合批，墙脚采用连续地面渐变；采用局部接触遮蔽，不以全屏 SSAO 推测绘制贴片的厚度。
- 2048 影图按相机视野加高物体范围拟合，PCF 过滤和纹素对齐；静态投影只在相机栅格或投影物变换/可见状态变化时重绘。
- 角色遮阴读取当前塔和兽像的实际几何高度、位置与可见状态，沿用柔和 10% 上限；火盆暖色保留。
- 石材世界坐标程序高度微扰、冰晶亮边和金属局部高光，保留源图整体光影。不是全图 PBR 或新制法线贴图。
- 建筑水晶和火盆采用明确对象范围的局部光晕，8 方向纹理采样；正常遮挡和淡化，视锥外不绘制，不改技能。
- 环境中性色冷灰调节；角色、技能和 HUD 保留原输出。地图根据设备能力使用至多 8 倍各向异性；角色继续最近邻采样。
- 「画质对比」整体 A/B；「画质细项」可分别关闭接地、材质、光晕、调色。轻量档继续保留基础战斗辨识。

真实透射/折射、全屏反射、景深和运动模糊本轮评估不启用，资产前提与重开条件见维护清单 Q14、Q18。原有几何、遮挡、雾、风雪和成熟战斗表现经过回归后保留。

## 同条件画面与指标

真实 Chrome / WebGL，视口 1600×900、内部 1920×1080、45°，每组基础与优化版本使用同一相机与同一比赛时间 1/60 秒。截图在切换后再次绘制，调用数为该静态样本，不包含第一次刷新阴影图的峰值。

| 场景 | 基础绘制调用 | 优化绘制调用 | 原影图每格世界尺寸 | 优化每格世界尺寸 |
| --- | --- | --- | --- | --- |
| 中央 | 82 | 69 | 3.125 | 0.71875 |
| 外塔 | 85 | 76 | 3.125 | 0.71875 |
| 圣所 | 99 | 94 | 3.125 | 0.84375 |

缩小影图每格覆盖范围提高了局部精度，实际像素密度取决于视野与缩放。静态调用减少来自缓存和视锥裁剪，不能外推为镜头移动时同样的成本或全设备 FPS 保证。

截图：`central-baseline.jpg` / `central-enhanced.jpg`、`tower-baseline.jpg` / `tower-enhanced.jpg`、`sanctuary-baseline.jpg` / `sanctuary-enhanced.jpg`。`quality-controls.jpg` 为实际游戏中的独立开关。

四个效果逐个关闭后读取实际帧缓冲，均出现非零像素差异，详见 `report.json` 的 `effectDifferences`。接触影、光晕与调色是主要可见变化；程序微表面保持克制，避免在已有石材纹理上增加过强噪点。

## 验证

- `npm test -- --reporter=dot --maxWorkers=2`：135 个文件、740 项测试通过，含新增 5 项阴影覆盖/缓存、接触连续性、建筑可见性和资源所有权测试。
- `npm run build`：TypeScript 与 Vite 生产构建通过。
- `node scripts/validate-three-quality.mjs`：三场景 A/B、四个独立开关、基础/优化/自定义交互、暂停、五次重开，以及 1280/1920 和 0.4/0.65/1.5 缩放、平移、拾取通过。
- 投影往返拾取误差小于 1e-8；画质切换、平移和缩放未改变比赛实体数据。
- 质量专用场景五次重开均为 112 个几何体、35 张纹理；战斗回归场景五次重开均为 97 个几何体、42 张纹理，各自稳定。
- `node scripts/validate-three-combat.mjs docs/visual-validation/2026-10-19/quality-optimization/combat`：原 Q/W/Q3/R/EQ3、护盾、点燃、闪现、正常键盘输入和实际声音输出通过，结果另存 `combat/`。
- 浏览器没有 shader 编译错误、页面错误或资源失败。借用源几何和贴图的光晕只释放自己的材质；接触模块释放自己拥有的资源。

构建后用 `npm run preview -- --port 4179`，再运行 `node scripts/smoke-three-production.mjs docs/visual-validation/2026-10-19/quality-optimization` 检查实际产物。结果存为 `production-report.json` 和 `production-smoke.jpg`。

## 回退和维护

基础对照通过 `ThreeArena.setEnhanced(false)` 回退本轮新增画质层、影图策略与采样提升；保留之前的地图和战斗迁移。四个细项分别调用 `setQualityEffect`，不改变模拟。主要调参入口为 `src/render-three/QualitySettings.ts`。

新增会投影的几何动画时，需要把几何变动纳入影图缓存失效条件；GPU 顶点位移若要产生同样的动态阴影，还需要同步深度材质。不要仅更新颜色 shader 就宣称动态投影完成。
