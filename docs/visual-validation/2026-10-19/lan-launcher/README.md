# Windows 局域网图形启动器

项目根目录双击 `启动局域网对战.vbs`，隐藏 PowerShell 控制台并显示 WinForms 启动窗口；首次显示自动启动对战服务。

窗口提供局域网网址选择、复制网址、浏览器打开、停止／重新启动服务，以及可展开日志。网址从实际服务启动输出读取，不向其他玩家提供回环地址。多个 IPv4 地址时可从下拉框选择。

Node.js 直接作为启动器的子进程运行，工作目录固定为项目根目录；自动选择 5180–5190 内的空闲端口。标准输出／错误异步读取并在 UI 定时器中消费，避免启动期间冻结窗口。停止与关闭只结束启动器持有的子进程树，不操作其他服务。未安装 Node.js 或 tsx 依赖、进程异常退出和启动超时会在界面显示原因，详细输出保留在日志中。

## 实际验证

- `powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File scripts/start-lan-gui.ps1 -SmokeTest` 通过：窗口显示实际 IPv4 地址，HTTP 页面 200，`/battle` WebSocket ping/pong 成功，“复制网址”和“打开游戏”按钮可用。
- 自动化自测不写剪贴板，不打开浏览器；复制动作使用 WinForms 的系统剪贴板接口。
- 默认端口空闲时选择 5180。第二轮由测试持有 5180，启动器自动选择 5181，原监听保持运行。
- 关闭窗口后，启动器启动的服务进程已退出。结果见 `report.json`，窗口截图见 `launcher.png`。

这是 Windows 启动入口，依赖本机 Node.js 和已经安装的项目依赖，不是自带运行时的独立安装包。对方玩家只需浏览器；主机关闭启动窗口会中断本机承载的对局。
