# 实机积雪反馈修订

用户明确反馈上一版“不符合积雪的感觉”，并提供有覆石、雪帽和起伏的参考局部图。上一版视觉不通过；当时测试通过不能替代美术认可。本轮已移除地面程序染白雪斑，接入新的积雪覆石素材。状态：修订实现和检查完成，待用户视觉确认。

[打开实际画面对照](comparison.html)。默认显示墙根的上一版历史截图与本轮实机；桥面也保留上一版。历史截图来自相同镜头，但不冒充严格的当前代码 A/B。切换「关闭 / 开启冰雪景观」可查看本轮同时间同镜头的独立开关对照。

## 问题与修订

- 原实现用噪声把平面地面染白，缺少雪包轮廓、厚度、覆盖石块和底部接触关系；已完整移除这段雪着色器。保留本轮之前的冰面、晶光与桥外垂冰。
- 内置 imagegen 依据用户参考生成透明积雪覆石素材，白色上表面、蓝紫阴面、石上雪帽和边缘碎雪由素材提供，原始最终图片与[完整提示词](../../../../assets/map-modules/howling-snowbanks-v2/prompt.txt)已保存。
- `SnowBanks.ts` 使用浅浮雕和最多 11 世界单位的几何起伏，维持固定 45° 源图投影，避免把整张雪图立成高墙。增加紧贴脚部的合批接触影，雪、石和角色仍按深度遮挡。
- 全桥 18 组独立雪石组合，宽度变化，避让草丛、火盆及中央兽柱；不是从桥头铺到桥尾的连续白带。近侧向内留出可见距离，让雪包轮廓不全被栏墙吞掉。
- 保留原有墙边装饰，没有加入用户排除的浮雕、残旗和盾牌组合。道路、碰撞、输入与伤害规则未因积雪修改。

本素材是固定视角绘制美术与浅浮雕，并非完整可旋转的三维雪体。当前复用一张雪石素材，以位置、尺寸和裸露间隔组织层次；后续若用户认可，可再做更多形状变体。

- [专项浏览器报告](report.json)：无页面 / Console / shader 错误或失败；相同时间重复渲染、相机平移复原、拾取、独立开关、轻量档与五次重开检查通过。
