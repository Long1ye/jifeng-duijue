## 实际变更

| 条目 | 正常游玩中的变化 | 实现和维护边界 |
| --- | --- | --- |
| Q05 | 石板凹凸跟随原有石纹、接缝，减少独立正弦纹理感 | 原纹理四邻域、间距两源纹素、alpha 加权的局部高通高度近似；高度系数 6、响应 0.36。属于风格化表面响应，不是正式法线资产 |
| Q06 | 积雪和干石材质有更明确的区别，亮部保留绘制细节 | 亮色低饱和遮罩内减少 75% 的额外石材对比，增加 0.10 强度的宽冷光；按剩余亮度空间限制高光，保留团队色 |
| Q11 | 飘雪集中覆盖实际视野，前后层次、风向更清楚 | 复用原 240 个顶点及单批 Points；三层尺寸和高度、共享风、世界坐标循环及边界淡出，战斗中心密度权重最低 0.35；不添加整屏雾 |
| Q17 | 缩小时细节逐渐退去，减少细石纹噪声 | 根据屏幕像素覆盖的源纹素数量，在 1.5～4 的区间衰减细节；沿用已有采样策略 |

天气使用模拟时钟，暂停时停表；「风雪层次」可独立关闭，轻量档关闭飘雪。基础档恢复旧散布。火盆余烬在增强天气下放大 30%，顶点数量不变。

没有新增图片、音频、渲染目标或材质绘制通道。石材增强路径增加四次邻域纹理采样；雪增加一个静态 seed 属性，约 2.8 KB。成熟技能表现、音频和比赛规则沿用已有方案。

- 雪层从模拟时间 2 推进至 2.25 秒有变化，重复 2.25 秒截图差异为 0；粒子仍为 240。平移不推进时间，独立天气开关及主开关恢复通过。
- 完整场景暂停诊断暂时关闭硬件 DITHER，记录原始像素差：五组局部最大为 5 像素、1/255；检查容差为 32 像素、4/255。没有将完整场景宣称为逐位一致。完全雾化桥墩 1263 个采样差异为 0。
- 五次静态重开均为 145 个几何、36 张纹理；五次比赛重开均为 141 个几何、57 张纹理。两套场景分开统计，未见递增。
- [战斗回归](combat/browser-report.json)：成熟技能、音频输出、暂停和重开通过，错误与失败数组为空。
- [生产包检查](production-report.json)：单个 Three.js 渲染画布、26 个音频文件、HUD、画质切换与暂停通过；页面共有 5 个 canvas，包含独立的二维血条画布。

这些是功能、资源稳定性及短时浏览器检查，不构成持续对局的帧率保证。正常游玩对照保留本轮真实增量，后续视觉反馈直接续写路线图原条目。

## 重现

开发服务位于 5173 时，顺序运行，避免开发热更新中断另一验证页面：

```powershell
node scripts/validate-three-quality.mjs docs/visual-validation/2026-10-19/quality-round5
node scripts/validate-three-gameplay-quality.mjs docs/visual-validation/2026-10-19/quality-round5/gameplay --incremental
node scripts/validate-three-combat.mjs docs/visual-validation/2026-10-19/quality-round5/combat
```

维护入口：`QualitySettings.ts` 集中参数；`SurfaceResponse.ts` 管理材质；`BridgeAtmosphere.ts` 管理天气；验证脚本中的增量模式仅切换 `surfaceRefinement` 与天气。
