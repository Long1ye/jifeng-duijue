# 红蓝建筑与装饰阵营区分

替换所有外塔、内塔与双守卫塔的美术为新防御塔资源；红蓝阵营各有独立贴图。召唤水晶使用新生成的红蓝独立低矮晶座，基地水晶保持原造型。

阵营色覆盖基地水晶的能量、独立防御塔与召唤水晶、装饰冰晶、独立墙旗及圣所后墙自带旗帜。积雪、灰石与火焰保持统一；中心的独立旗帜为中性色，桥下自然冰挂保留自然冰色。材质按阵营分批，纹理仍按素材共享。

已复查蓝方与红方圣所的真实 45° 镜头，确认新塔脚线、晶座比例和配色。截图 blue.jpg、red.jpg；素材页 assets/map-modules/howling-team-structures-v1/index.html。

验证：7 个相关测试文件、22 项测试通过，覆盖独立红蓝贴图、召唤水晶与基地资源分离、色彩保护、旗帜风动组合、分批与资源释放、塔选择及摧毁隐藏。TypeScript / Vite 生产构建通过；浏览器错误日志为空。
