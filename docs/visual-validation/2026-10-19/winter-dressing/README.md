# 冰雪景观试版

后续用户已明确否定本页的积雪表现。程序染白雪斑已被移除，当前修订见[积雪实机反馈修订](../snow-bank-revision/README.md)。本页保留历史记录，不代表当前游戏效果。

用户明确排除目标图中新增的浮雕、残旗、盾牌组合。本轮保留已有墙边装饰和布局，试做其他冰雪变化。视觉状态：待用户确认。

[实际游戏画面对照](comparison.html)：桥面、墙根、红方外塔、中央桥段、圣所五组。左右来自相同镜头、模拟时间 2 秒、1600×900 视口，仅切换「冰雪景观」。默认缩放 0.6，中央桥段 0.4。可在游戏「选项 / 练习」的画质细项开关「冰雪景观」；总画质切换也能回退。

## 实际加入

- 墙脚随位置变化的雪斑：不规则宽度、缺口、颗粒与边缘明暗；火盆附近雪量随实际光源削弱。
- 路肩八处薄冰：保留原铺地底纹，局部冷色、静态裂纹和宽反光。中央主路及圆纹章保持开敞。
- 建筑局部晶光：从实际建筑位置向附近桥面衰减，红蓝分别着色，跟随源与父级变换、可见性和淡化；摧毁的外塔不继续照亮地面。
- 五组较长桥外垂冰：复用已存在的垂冰图片，合并为一个绘制批次，正常深度测试，不进入拾取集合。

积雪和薄冰是既有地面材质上的风格化表面绘制，不是新增雪堆体积、真实冰壳或折射。保留成熟火焰、战斗、音频与远景，没有加入新兽首或重制远处建筑。

首次截图发现连续雪带过于整齐；已修订为宽窄不一、有缺口和露石的雪斑。只把游戏截图作为实际效果；此前生成的目标图仍是概念参考。

## 验证

- 全量测试：144 个文件、795 项通过；TypeScript / Vite 生产构建通过。
- [专项浏览器报告](report.json)：无 Console / shader 错误及失败；独立开关、相同时间暂停、镜头平移复原、地面拾取、隐藏晶体源、轻量档、总画质回退和五次重开通过。
- 本次固定镜头稳定绘制调用由 81 增至 82；五次重开均为 163 个几何、36 张纹理，无持续增长。该数量属于本报告的无兵线场景，不与不同场景的历史数字直接比较。
- 新模块拥有一个合批几何、一个材质和一张已存在图片的纹理对象。地面处理增加程序噪声、局部光源和裂纹计算；无新增渲染目标。轻量档关闭冰裂纹细算，保留基本雪冰颜色。短时功能检查不构成设备帧率保证。
- [正常比赛回归](gameplay/report.json)：实际移动、兵线、攻击、Q、暂停和五次重开通过。[正常比赛查看器](gameplay/comparison.html)比较全部基础/优化效果，区别于本目录只切换本轮冰雪的专项对照。
- [战斗与音频报告](combat/browser-report.json)：成熟技能表现、声音、暂停及重开回归通过，无错误及资源请求失败。
- 新测试覆盖实际晶光源的变换、队伍颜色、透明淡化、销毁/父级隐藏，以及新旧资源所有权、重复释放和加载回调边界。

参数集中在 `src/render-three/WinterDressing.ts` 的 `WINTER_DRESSING`。它只借用原地面材质与光源；新增垂冰独立释放，未修改模拟、碰撞、通行、伤害或音频。
