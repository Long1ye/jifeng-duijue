## 根因与改动

旧布局仅按原雪堆锚点及少数对象避让。新增纯雪包、厚雪和风脊比旧的雪石条有更宽的完整轮廓；它们和魄罗巡游区、地面冰晶的屏幕范围重叠，正常深度测试因此把原物件埋住。

`SnowClearance.ts` 为魄罗整个 authored 巡游范围、左右翻转与行走尺寸、脚部和头部留白；为原有地面/柱脚冰晶保留完整轮廓，并检查草丛、火盆和中央兽柱。计算来自现有布局常量。积雪完整图像在固定 45° 下为仿射投影，用四角求包围框，不在搜索时反复生成 GPU 几何。

普通雪堆先尝试沿桥移动和缩小；柱脚、融雪和草根保持其原物件锚点，仅缩小或在冲突时去除。火盆雪环和草根雪可包围自己的对象，但仍避让魄罗、冰晶及其他物件。冲突雪堆从 56 组调整至 45 组，八种类型均保留。未通过全局置顶、关闭深度测试或挪动原物件来掩盖冲突。

## 验证

- 专项测试覆盖：旧布局能复现魄罗与冰晶范围相交；修正布局对所有保留区没有相交；解析包围框包含每个雪图网格顶点，八种类型仍存在，火盆与草根保持附着原物件。
- [修正后浏览器报告](after-report.json)记录所有六个视角、完整布局、资源和冲突列表；页面与 Console 无错误，冲突列表为空。
- 实机检查了魄罗完整身体、脚部接地、地面冰晶底座与尖端；保留物件和积雪原来的深度测试。对巡游路线的保证来自完整 bounds 的覆盖检查，静态截图不冒称为完整路线录像。
- TypeScript / Vite 生产构建通过；为通过当前工作区编译，另将既有 `three-wildlife.test.ts` 的模拟纹理声明补为 `Texture<HTMLImageElement>`，仅修正测试类型，不改动物行为。
- 本轮全量测试：152 个文件、821 项通过；积雪相关三文件七项专项通过。
- 复用现有雪图、合批材质和纹理，没有新增纹理、绘制通道、渲染目标或逐帧避让。布局只在初始化时求解，暂停和重开沿用原规则。

视觉认可仍待用户复查。包围框避让比精确逐像素轮廓保守，因此部分原雪堆被缩小或移除；这是本轮优先保证原资源可读性的取舍。
