# 重叠单位拾取修复

原问题：Three.js 只取最近射线交点，我方小兵会遮住后方敌方目标；原代理直接使用碰撞半径，小于实际躯干宽度。

实现：

- 游戏拾取对候选单位优先选择敌方，统一影响左键选中、右键攻击、A 点击、指向技能和召唤师目标。
- 隐藏的角色代理使用躯干横向宽度，保持原碰撞尺寸、攻击距离和人物绘制。
- 代理边缘外增加最多 5 CSS 像素容差，随页面尺寸计算；精确命中的敌人优先于边缘辅助候选。
- 同类命中按鼠标到躯干中心的归一化距离排序，无固定英雄优先级，保留补刀选择。无附近敌人时仍可选中友军；死亡代理照常移除。

验证：`tests/three-target-picking.test.ts` 覆盖重叠友敌、不同敌方单位、分辨率/缩放、容差边界和空地；原射线与资源测试继续通过。生产构建通过。

全量 139 个测试文件、778 项通过。默认 5 秒超时首次运行中，既有正常兵线长模拟测试超时；使用 `npx vitest run --testTimeout=15000` 全量复验通过，未更改该测试或全局配置。

`node scripts/validate-three-target-picking.mjs` 在真实 ThreeArena / Match 中构造重叠场景，验证敌方小兵、英雄上身、补刀目标、攻击命令、死亡排除及空地移动，7 项通过，浏览器错误为空。结果见 [报告](report.json)。验证场景位置仅用于自动化复现，正式游戏没有加入传送或属性调整。
