# 圣所与建筑序列调整

基于用户圣所截图，拉开基地水晶、双守卫塔、召唤水晶和内塔的距离，并同步调整两端基地及共享地图点位。

蓝方桥坐标（红方建筑关于桥中心镜像）：

| 建筑 | u | v |
| --- | ---: | ---: |
| 基地水晶 | -636 | 0 |
| 双守卫塔 | -562 | ±54 |
| 召唤水晶 | -500 | 0 |
| 内塔 | -425 | 0 |
| 外塔 | -280 | 0 |

雕像后墙退至 v=-145，清除墙脚重复火盆；基地前侧沿栏保留两处独立火盆。圣所预设镜头中心移向建筑序列中部，以显示完整构图。

实机检查：固定 45° 下复查圣所和外塔，双守卫塔与雕像墙分开，水晶之间留出道路。before.jpg 与 after.jpg 保存修改前后视图。

验证：5 个相关测试文件、21 项测试通过，覆盖地图内点位、出生及兵线、内外塔攻击圈间隔、渲染与交互；TypeScript 和 Vite 生产构建通过。
