# 小部件布局清理

依据用户提供的五张实机局部截图，调整现有素材的位置与密度，未生成新素材。

- 移除孤立的路面灯、散落杂物和额外积雪贴片；补给归并到两侧靠墙的两组。
- 冰晶避开挂灯、旗帜与草丛，取消同一位置的多层冰晶堆叠，保留靠墙、墙顶和桥下的少量点缀。
- 挂灯选择实际墙柱挂点，避开草丛的完整画面轮廓；链条使用相邻空墙段。
- 排水口回到墙边，中央道路和圣所通行区域保持开阔。

已检查固定 45° 实机镜头下的冰晶区域、圣所与中央桥段。截图：ice.jpg、sanctuary.jpg、central.jpg。

验证：相关 7 个测试文件、17 项测试通过；TypeScript 与 Vite 生产构建通过。新增镜头投影测试覆盖灯具与草丛画面轮廓的相交问题。
