# 第四轮：正常游玩中的接地、建筑体量和光晕

2026-10-19。按原文档 Q01 → Q02/Q03 → Q15 继续实施，前几轮证据保持原样。

## 实际修正

| 项目 | 问题 | 本轮结果 |
| --- | --- | --- |
| Q01 角色地影 | 圆形外影不显示走路和出招轮廓 | 使用当前角色帧的 alpha、镜像 UV，按固定 45° 恢复竖直高度，沿太阳方向投影；保留脚底接触、击飞移动和淡化。复用原外影 Mesh、几何和已有图集，不增加每角色影子绘制；每帧更新包围球，避免错误裁剪 |
| Q02 铺地投影 | 原阴影接收面低于塔基铺地，部分投影被盖住 | 新增一个合批铺地接收面，高度 0.84，匹配铺地圆形透明边缘；太阳影图、PCF、缓存继续沿用；轻量档关闭 |
| Q03 建筑接触暗部 | 原接触影 0.66 低于铺地 0.68，且足迹与衰减过窄 | 建筑/墙脚接触层改为 0.98，扩大足迹，采用平顶柔和衰减，透明度 0.30；角色投影 1.04、脚底接触 1.08，避免铺地覆盖；隐藏或销毁源后不保留暗部 |
| Q15 建筑光晕 | 原 4 源纹素半径在正常比例下太窄 | 外半径 10 源纹素、内半径为其 45%，双圈共 16 次纹理取样，透明度 0.22；仍只对塔、抑制器、火盆，不对角色、技能或雪发光 |

## 验证与代价

- 当前完整测试集：136 文件、751 测试通过；新增当前帧镜像投影、击飞偏移、本体不变及铺地接收面高度/合批/所有权检查。
- `npm run build` 通过；[生产包检查](production-report.json)零页面错误、零请求失败，实际 Q/W、轻量、画质切换和暂停通过，26 个音频文件加载成功。
- [正常比赛报告](gameplay/report.json)：零页面/资源错误。活动角色的投影共享当前本体图集且 UV 相同；正常走动时单个英雄投影实际影响约 2400～3400 个像素；出生镜头铺地接收面约 9600 个像素出现有效阴影。这里只用数字确认效果没有被遮住，感知结果以正常比例对照为准。
- 正常比赛执行到阵亡后，五次重开稳定为 147 几何体、58 纹理；常规三场景和专项验证后稳定为 144 几何体、36 纹理。不同流程暖过的现有动作图集不同，不直接用这两组计数相减判断泄漏；本轮没有新增角色/地图贴图或渲染目标。
- [画质报告](report.json)：平移、1280/1920、三档缩放、地面拾取、暂停、原五个专项和资源检查通过。桥下 1263 个完全雾化投影样本仍与背景一致，最大差 0/255。
- 绘制调用中央基础/优化为 82/70、外塔 85/77、圣所 99/95；相较第三轮，优化档各增加 1 次合批接收面绘制。角色地影复用原绘制，光晕增加每片元 8 次纹理取样；另外增加少量四顶点更新和包围球计算。短静态时序不作为全设备或交战 FPS 保证。
- [成熟战斗与音频回归](combat/browser-report.json)：技能、Q3/R、EQ3、护盾、召唤师技能、塔毁坏、普通输入及可测声音输出通过。

## 回退与维护

「接地暗部」关闭时角色恢复旧圆形地影，同时关闭新增脚底及建筑接触；「建筑光晕」可独立关闭；「轻量档」关闭铺地实时投影接收与光晕；「画质对比：基础」整体恢复旧表现。原战斗、音效和比赛数据保持原逻辑。

后续修改平面高度时必须检查完整层次：地面 → 原接收面 → 铺地 → 新铺地接收面 → 建筑接触 → 角色投影/接触，不能只验证 shader 编译和参数变化。
