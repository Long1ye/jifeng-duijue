# 冰桥居民：魄罗与寒鸦第一版

[12 秒连续实机演示](http://127.0.0.1:5173/docs/visual-validation/2026-10-19/wildlife/motion.html) · [进入正常比赛](http://127.0.0.1:5173/three.html?map=howling&scene=match)

## 本版行为

5 只魄罗：保留出生区两只与中央一只，在蓝、红连接路段各增加一只。休息间隙嗅雪、抖毛或小跳，沿作者规定的封闭范围走动，英雄靠近会停下观察。沿途居民位于雪堆前方空地，避免埋入雪堆。动作在复用贴图上施加小幅姿态变化，不宣称新增了独立的逐帧嗅雪动画。

3 只寒鸦：蓝侧、中央、红侧远端栏杆各一只。八姿态包含停栖、回头、理羽、起飞、三段扑翼和落地；每只在两处邻近雪帽间飞行，停留时长错开。落点依照真实栏杆 run/cut、源图雪帽顶线与地脚投影求出，不使用悬空的固定高度。飞行不进入主路中心。

本版不新增音效；桥下远景飞鸟、雪鼠、双只追逐留待后续。使用已有魄罗动画，不替换战斗素材或声音。

## 迷雾与生命周期

由比赛时间驱动；暂停时位置、姿态不变化，时间回退后复位。环境生物不是 Match 实体，没有碰撞、血条、目标或点击代理。只向行为模块传递当前玩家能看到的英雄，避免隐藏敌人通过转头或惊飞泄漏位置；视觉仍经过场景迷雾压暗。

`ThreeArena.wildlifeEnabled = false` 可关闭全体环境生物以隔离效果，默认开启。该维护开关没有加入玩家菜单。魄罗位置与范围集中于 `PORO_PLACEMENTS`，寒鸦落点由 `ravenPerches()` 和 `wall-caps.json` 维护；更换栏杆素材时应重新测量雪帽坐标。

## 素材与成本

寒鸦使用 game-assets/Meowa 通用生成制作的 `raven-atlas.png`（1024×768，RGBA，8 姿态）；`manifest.json` 记录裁切与脚点。源图未缩放或再次像素化。透明度以实机 alphaTest 验证，无矩形背景；这一通用生成素材不宣称具有严格的 64px 像素网格。作业 `job_9e8b0dff26f8461a82a948dd955ae1f9`；原任务下载遭遇 Windows 长路径后，通过同一作业轮询至短路径恢复，没有重复生成。

原有 3 个魄罗休息素材改为各只共享，增加居民不重复加载相同素材。寒鸦共用一张图集，独立 UV 和脚点；不分配新渲染目标。相比原版最多新增 7 次可见绘制（两只魄罗与接地影、三只寒鸦），实际受视锥裁剪影响。
