## 兽像的位置与地图范围

两侧各六根兽像柱，柱心位于 v=±128，玩法桥宽为 ±112。u=-320、-192、-64、64、192、320 与下方承重墩对应；主要雕花柱上方才有兽像，中央通道没有直接摆放兽像。源图最近的脚角与柱心分开计算，避免把图片角点当作占地中心。中央延展范围 u=[-340,332]；中央徽记只出现一次。

已校正墙与桥边的斜率、墙段留缝、柱脚位置、栏墙过高、火盆遮挡、突兀的方块承托、桥边压条过厚和桥墩底部悬空截断；静态栏墙已合批。截图中的调用数随窗口与裁剪范围变化，不能当作 FPS 性能结论。
