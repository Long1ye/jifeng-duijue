## 查看入口

`/three.html?map=howling` 默认进入 P2 正式样板、S01 战斗场景；`/three.html?map=howling&look=gray` 进入保留的 P1 灰盒。顶部选择器可切换两种画面；旧版 `/?map=howling` 继续保留。

样板角色初始位于 `bridgePoint(-145,0)`，蓝方外塔位于原 `bridgePoint(-195,0)`。详细美术范围仍为 u=-280..80 / v=-112..112；外围保留简化地面与诊断建筑，不能把正常出生区的简化状态当作全图已升级。可用“查看 S01 样板区”和“查看中路”移动镜头。

## 资产契约 v1（样板用，未冻结为全图规范）

- 世界坐标：延续 P1 等距映射；旧模拟、伤害、射程、塔位与通行规则不改。
- 地表：64×64不透明PNG，每格64世界单位，最近邻，无mipmap；相机俯角默认60°，允许45/75比较。P1的32/64诊断纹理只在灰盒模式可切换。
- 立体模块：世界尺度UV尽量保持每64世界单位一张64像素材质；结构静态批次按材质合并，地表实例化。
- 角色：读取实际图集宽高推算行列，不猜测每个动作的列数；脚底锚点来自旧清单，仅读取屏幕朝向用于选帧，不改模拟朝向。
- 原始像素不重绘；角色材质冷暖乘色与alphaTest=0.35为当前候选。硬透明阈值可能影响软边，必须作为实机验收重点，不能视为最终固定值。
- 显示：内部宽640、DPR1、随容器比例调整高度；像素采样及非整数窗口缩放继续验证。阴影图2048是候选配置，未作性能保证。
- 资源来源、哈希和任务信息见 [素材记录](../../../../assets/map-modules/arpg-s01-v1/README.md)。
