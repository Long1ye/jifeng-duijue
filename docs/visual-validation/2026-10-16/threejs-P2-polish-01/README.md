## 变化与目的

| 方面 | 精修内容 | 需要在实际画面中确认 |
| --- | --- | --- |
| 材质统一 | 在光照前对石板、墙体和苔藓分别压低饱和度、统一冷灰倾向；材质参数集中在S01Look；地砖明度变化收窄至0.93–1.0 | 道路是否偏灰或过暗，苔藓是否适量，重复纹理是否仍明显 |
| 纹理尺度 | 塔体几何改用和桥体一致的世界尺度UV；底座先按实际比例缩放几何再计算UV | 八角转折接缝、凹窗侧面和不同镜头距离的采样稳定性 |
| 桥体层次 | 栏墙压顶按实际墙高对齐；增加压顶下暗线、桥沿腰线及支撑柱脚层级 | 压顶/腰线是否过亮，破损轮廓与桥下纵深是否自然 |
| 外塔层次 | 增加基座与冠部暗槽、凹入尖拱窗、窗内暗面和金属竖梃、破损侧旗片；原有逻辑锚点与占地规则不改 | 建筑是否厚重，窗洞与旗片是否清晰，角色近身绕行是否穿插 |
| 光影 | 减低半球光与暖主光、加入低强度冷色侧补光；火盆范围/强度和脉动更克制；场景采用ACES高光压缩，调整桥下雾范围 | 暗部仍可读、石面不洗白、火光不过曝；硬边阴影质量与实际帧率 |
| 角色接地 | 以32×32程序化像素阶梯透明遮罩替代硬边圆盘，阴影中心较深、边缘渐隐，击飞时变淡和扩散 | 脚底位置、阴影尺寸、移动时的漂浮感和地表重叠 |
| 角色环境融合 | 降低原固定染色的侵入性；按与火盆的平面距离和同一比赛时钟轻微加入暖色，暖色混合上限0.24 | 角色原有身份色是否保持、靠近火盆是否自然；这是美术近似，不是二维角色真实PBR受光 |
| 遮挡可读性 | 玩家位于塔后且屏幕躯干与塔重叠时，塔体逐渐淡到0.48；仅塔自身独立材质改变透明度，地面不跟着变淡 | 塔冠/旗片透明排序、淡出范围和是否影响空间感；暂停冻结、重开恢复 |

全屏不增加模糊；像素采样、原动画时间、命中时机和模拟逻辑保持原约定。血条和角色贴片不参与场景ACES色调映射，避免高光压缩改变战斗提示与角色辨识度。环境照明仍只来自场景，技能与弹道不新增照地光。

## 实现与维护

- `src/render-three/S01Look.ts`：材质调色、环境光参数、火盆位置/脉动、角色环境染色、接触阴影遮罩与遮挡判定。
- `S01Environment.ts`：几何细化、世界UV、塔体独立材质和透明度过渡；共享贴图仍统一释放。
- `ActorSprites.ts`：共享接触阴影贴图、逐角色染色、悬空阴影变化，退出时释放新增遮罩。
- `ThreeArena.ts`：正式场景色调映射与雾、玩家上下文传给遮挡表现；P1灰盒仍使用原无色调映射对照。
- [source-before.zip](source-before.zip) 保存本轮修改前的render-three模块，供代码对比；不含完整游戏媒体或其他源码，不是整项目恢复包。

材质调色通过当前Three.js WebGLRenderer的onBeforeCompile接入，按材质角色提供独立程序缓存键；复制塔体材质时显式保留回调和缓存键。[Three.js Material说明](https://threejs.org/docs/pages/Material.html)与本地0.186.1 shader chunk已核对。构建不会验证GPU上的GLSL编译，不能把TypeScript通过表述为着色器已实机通过。
