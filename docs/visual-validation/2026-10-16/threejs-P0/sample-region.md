# P0 样板区域与测试条件

日期：2026-10-16。工程样板范围已选定；正式美术方向仍在 P2 实机验收。

## 区域 S01：蓝方外塔到中央桥段

采用现有冰桥局部参数范围 **u ∈ [-280, 80]、v ∈ [-112, 112]**。它覆盖蓝方外塔 `(-195,0)`、塔侧草丛 `(-270,-87)`、中段草丛 `(-90,-86)`、中央对侧草丛的一部分和连续道路；包括两侧桥沿及桥下远景。样板视觉可以重新设计，但当前通行、塔位和兵线规则继续使用旧逻辑。

- 主检查点 A：`bridgePoint(-195,0)`，建筑体量、绕塔、角色接地和遮挡。
- 主检查点 B：`bridgePoint(-90,0)`，道路 tile 过渡、草丛边缘与行军比例。
- 主检查点 C：`bridgePoint(-18,0)`，与 combat 练习同一区域，检查近战、Q/E 和特效判读。
- P1 灰盒先显示完整逻辑桥面与 S01 范围，便于检查坐标；P2 正式素材先集中 S01，不批量制作全图。

范围以 `Bridge.bridgePoint` 映射后的二维逻辑位置为准。u/v 只是作者布局参数，不能直接作为模拟距离或再次应用原斜投影。P1 采用逻辑 `(x,y)` 到 Three 世界 `(x-3100, height, y-1700)` 的等距映射，建筑视觉高度单独处理。

## 首轮样板交付

道路地表及中心/边缘/转角/雪或苔藓过渡，一段破损桥沿及立面，一座外塔基座与建筑体块，一处暖色火盆焦点，近景残块和桥下远景。先比较 32/64 纹理候选、固定俯角和现有角色比例，再确定材质规格。火盆位置从新版构图决定，不增加模拟碰撞。

整体以 Eldest Souls 的结构厚度与空间为骨架，借鉴 Hunt the Night 的环境细节；中央道路低噪点，丰富细节主要落在边缘。需要明确展示相较旧版的提升，不能以旧平面贴图贴到三维平面上作为完成样板。
