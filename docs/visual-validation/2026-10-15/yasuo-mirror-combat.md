# 双方亚索与近战判定调整

修改顺序：敌方切换亚索 → 体型和范围 → 身体选取 → 近战普攻 → Q 贯穿 → 双方命中反馈 → 回归验证。

- 双方复用现有八向 16 帧待机、走路及 A/B 攻击素材，动画时钟和 E、EQ、蓄风特效独立。以蓝红血条及脚圈区分阵营。
- 敌方技能切换为 Q/W/E/R、蓄风、Q3、EQ；AI 等待已开始的动作完成，避免下一次决策打断自己的 Q。
- 世界坐标基准：英雄身体约 78 高，小兵约 42 高；脚下碰撞半径分别为 11、7。选取采用身体椭圆与脚部区域，不读取含刀刃、透明边距的整张精灵矩形；重叠时优先脚部直接点击，否则按前后遮挡选择。
- 普攻范围 54；Q/E 范围 145；E 位移 170，保证最大距离目标后方仍有穿身空间；Q3 范围 290、速度 250。该版本是项目内比例校准，不声明复刻原版所有数值。
- 普攻出刀即结算，脱离范围会取消前摇，不再发射英雄普攻弹道。远程小兵和防御塔仍发射弹道。
- Q1/Q2 在第 22/37 帧对应的约 0.428 秒结算整段戳刺，半宽 6 加目标脚部半径。贯穿多个敌方单位，每个目标一次，整次施放最多获得一层蓄风；不命中防御塔，也不受风墙阻挡。Q3 仍是可被风墙阻挡的龙卷风。
- 身体上施放 Q/R 会指向该目标的脚下位置。Q 预览显示实际方向与宽度，命中停顿和反馈双方对称。

验证：459 项自动测试通过，TypeScript/Vite 构建通过。Chrome 实机双方待机与走路均覆盖全部 16 帧；双方普攻各造成 43 点伤害且无英雄弹道；一次 Q 同时对两只小兵和一名英雄各造成 85 点伤害，剑身闪光可见且无 Q 弹道；双方共四层蓄风特效位置独立；身体选取和空白区域排除通过。该次实机读数约 165 FPS，无浏览器异常。
