# 冰桥建筑与草丛布局 v1

本轮交付：地图布局与场景构建。现有外塔继续使用原对局逻辑；新增内塔、双守卫塔、召唤水晶和基地水晶为场景布局，尚未增加血量、攻击、拆除顺序和胜利规则。五片草丛已搭建连续外观及共享区域数据，视野隐藏尚未实现。

## 布局坐标

使用桥面局部 u/v，u=0 为中央，u<0 为蓝方。围栏保持连续直线，中央兵线通道保持开放。唯一布局源为 assets/map-studies/howling-abyss-v1/layout.json，建筑碰撞预留、出生点、外塔实体、渲染及草丛区域共同读取该文件。

由基地向中路依次推进。内外塔使用桥宽对应的射程检查，攻击圆之间保留超过 40 世界单位的间隙；所有建筑预留矩形均位于可走桥面内。

每片草带由三排错落的覆霜草与蕨类组成，按材质合并网格；保留 brushId 与区域数据供后续视野系统使用。功能区规划与零散装饰植物分离，挪开与草区重叠的火盆。草丛中心和边界采样均在桥面内且不与建筑地基冲突。

后续功能：团队视野、草内互见、攻击暴露、盲打命中、不可见目标禁止锁定、AI 丢失目标，以及血条/特效/小地图同步隐藏。
