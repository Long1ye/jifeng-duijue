# 亚索 Q3 · Meowa 生成版

使用项目 game-assets Skill 的 `general-image-run` 生成，Image2.5 / Standard / 1K / 原生透明，无模板，总计 2 积分。

- 八帧旋风：`job_c934deaa10014b4cb173d6134fc4bd19`。
- 四帧命中上升风流：`job_9495ed81804547948bafd31ba56b2352`。

`generated/` 与 `hit-generated/` 保留原始最终 PNG 和生成清单；两张源图均为 1024×1024 RGBA、软透明。旋风原图 4 列 × 2 行，每格 256×512；命中原图 2 列 × 2 行，每格 512×512。

`scripts/package-meowa-q3.py` 只作技术切片和整数像素锚点对齐。旋风底端固定到每格 `(128,460)`，没有重绘或缩放；对齐偏移、内容范围、SHA256 与任务 ID 记录在 `contract.json`。`runtime/` 包含运行图集与慢放 WebP，`index.html` 提供原尺寸循环预览。

当前 Three.js 实机以约一人高显示旋风，采用低饱和灰白风带和透明风体，替换原有高亮蓝色漏斗与密集程序风环。旋风沿真实弹道移动，始终直立，出生与射程末端淡入淡出；目标命中后播放短上升风流并跟随击飞高度。原速度、射程、碰撞半径、穿透和击飞时间保持原值。

起手动作继续使用原有角色帧；只在 Q3 起手显示时过滤图集里自带的亮青色月牙，不影响 W 及普通动作。音效继续使用已有原版客户端声音。
