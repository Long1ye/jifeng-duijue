# 冰桥活草丛 v1

使用项目 `game-assets` Skill 的通用生成，以原草丛作为风格参考，制作六种独立雪草／芦苇；再用技能自带本地组件拆分工具无损拆分。生成成本 3 积分。

运行时资源在 `components/component_001.png` 至 `component_006.png`。均为 RGBA、透明边缘，尺寸依次为 289×414、278×407、275×307、279×311、290×295、307×248；六个组件已逐张检查，无组件拆分警告。生成原图保留在 `generated/`，未覆盖参考图。

`LivingBrush.ts` 在 WebGL 下用 Phaser Rope 将每束草划分成 12 段连续形变，直接复用六张原图，不生成弯曲图集。根部固定，草茎与草尖通过两级阻尼响应产生延迟；轻微的异相扰动让草尖不整齐往复。保持最近邻采样，不缩放或二次像素化源文件。Canvas 下回退为小幅根部摆动。蓝灰、浅紫与高芦苇变体组成三层草丛，按实际游戏高度约 48–96 世界单位呈现。

草丛沿用 `BRIDGE.brush` 原布局；不改变草丛隐蔽区域、碰撞或可走范围。新资源不是固定 128 像素角色动画素材，也不宣称逐像素碰撞或真实物理植被。
