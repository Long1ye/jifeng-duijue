# 四图拆件与地图构建 v4

本轮按用户“所有美术地图 → 找齐部件 → 制作 → 按布局搭建”的要求扩大到整桥，不再把中央模块等距重复作为完整地图。

- [参考图标注、26 类部件覆盖表、共享布局示意与五件新资源](index.html)
- [机器可读部件清单](../../map-concepts/howling-abyss-target-v1/component-plan.json)
- 布置源：`src/render-three/PaintedMapLayout.ts`；建筑投影：`PaintedMapLandmarks.ts`；地面、栏墙、桥墩：`PaintedBridgeSample.ts`。
- 默认实机：`/three.html?map=howling`。场景参数：`scene=central|sanctuary|sample|overview|match`。

## 参考图的职责

01 提供圣所、石火塔、延伸桥路、兽柱、深渊的全局关系；02 提供晶坛在圆庭中央、后侧双神龛和开敞入口；04 提供四座错位兽柱夹持单个圆纹章；03 提供塔位圆铺装、开敞路段和桥边关系，但此前已否定的人像纪念碑不采用。

四张图没有共同标定摄像机和无缝边界。参考图上的点为人工识别的落点，未宣称精确测量三维坐标。游戏布置保留这些关系并适配连续通路，不能把每张独立构图都当成一幅已经完整复现的截图。

## 部件生产

本轮五件：晶坛与短阶（1374×1145 RGBA）、双神龛后墙（1672×941 RGBA）、正俯视圆铺地（1254×1254 RGB）、战斗塔（1024×1536 RGBA）、破损栏墙（1536×1024 RGBA）。尺寸、alpha 与来源哈希由 `scripts/audit-howling-painted-map.py` 读取验证并写入 [manifest](manifest.json)。其余二十一类复用 v3 建筑切片、现有地表/远景或几何/雾效果，逐项契约见覆盖表。

用 imagegen 技能的内置工具，五次原始生成、一次塔修订；没有 CLI API 回退，没有购买额度或调用外部付费服务。精确提示词为本目录的 `*.prompt.txt`。`*-candidate.png` 保留候选，不被游戏引用。最终 PNG 与内置输出逐字节一致，未做离线图像后处理。

初看塔/残墙预览有灰雾边；读取 alpha 后确认大量灰色位于完全透明像素 RGB 内。游戏使用原生 alpha、alphaTest .48 丢弃低透明度外缘，实机核对没有灰色矩形背景。不能只凭黑底预览断言透明失败。

## 布局修正

- 中央兽柱从十二座等距对列改为四座错位：远侧 u=-160、96；近侧 u=-96、160；v=±128。每座仍有对应承重墩，桥墩数量多于兽像。
- 主桥延伸至 u=±720，并按逻辑边界在基地端扩宽；中央圆纹章只出现一次。
- 晶坛位于 u=±580 的圆庭中心，双神龛后墙只在庭院后侧，入口和通往桥路的连接保持开敞；前后锚点在实机调整，避免晶坛偏在圆圈后缘。
- 外塔原 u=±195 与中央兽柱过近，调整为 ±350。同步逻辑布局数据，内塔保留槽位移至 ±490，小水晶槽位至 ±540；没有修改生命值、伤害、射程数值。当前玩法仍只启用两座外塔，其余槽位不是已实现的新建筑系统。
- 塔的画面点击代理覆盖新塔冠，但不改变战斗半径。塔摧毁时对应美术隐藏。
- 栏墙按连续区间裁取 UV，与破损墙/后墙衔接，避免跳过整段留下额外空缝。
- 火盆、晶簇是独立布置表，不再沿全桥机械等距阵列。
- 浅入口阶在可玩端界外向下延伸，不抬高逻辑地面。晶坛自带台阶。建筑未抬高整片道路，避免角色漂浮。
- 红端为同风格延伸，色调克制区分；原图未给出红方完整局部，不能标为原图已有内容。

## 质量边界

固定 45° 2.5D：通过每列脚线恢复近似高度/纵深，保留绘制投影，支持深度测试、接触投影及遮挡淡出。它不是可自由旋转的三维模型。圆铺地是正俯视材质，单独投影到地面；其圆边在 shader 内淡化，避免方形贴片边。角色、兵线和攻击仍使用真实 Match 宿主。

远景人像、冰瀑和断桥目前合在远景图层，未逐尊建模。火焰为静态绘制配呼吸光；神龛储物箱为环境美术，未新增商店交互。未声称风格与参考图达到像素级一致或通过用户最终美术验收。
