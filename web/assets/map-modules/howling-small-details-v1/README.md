# 冰桥小部件 v1

通过内置 imagegen 生成，参考当前 04—07 直墙细节概念图。没有矮植，没有重复生成木箱木桶。已在 PaintedSmallDetails.ts 中少量接入地图：小冰晶沿墙脚分布，挂旗/铁链/灯挂在后侧直墙，绳圈和篷布集中放在基地补给区。小冰晶压低亮度，格栅与雪堆平铺地面，摆放避开高草区域。零散矮植已从 PaintedDetails.ts 移除，高草区保留。

验证：生产构建通过，6 个相关测试文件共 20 项测试通过。当前围栏实墙较低，挂件比例仍可随围栏高度迭代。

12 个独立 RGBA PNG 位于 props/：三种小冰晶、蓝色挂旗、垂挂铁链、壁挂暖灯、排水格栅、绳圈、折叠蓝篷布、浅雪堆、零散小石、短冰挂。

atlas.png 为未修改的生成原图。manifest.json 记录独立素材尺寸、透明范围、原图裁切位置和 SHA-256。挂旗末端略跨第一行网格，拆分时按实测空隙调整了挂旗与下方绳圈的分界，没有重绘像素。所有独立图的 alpha 范围均为 0—255，保留半透明边缘。

提示词要点：透明 4×3 游戏部件图集，每格一个独立对象，匹配参考图的 45 度正交视角、冷蓝灰手绘材质和左上光照。依次生成三棱小冰晶、细长冰晶、扇形冰晶、雪花蓝旗、两端带固定环的垂链、带支架的暖灯、平置排水格栅、绳圈、捆扎蓝篷布、浅雪堆、小石块、短冰挂。冰晶应小而克制；排除植物、整墙、地面板、人物及场景背景。无需文字和分格线。

可复现拆分命令：python scripts/package-howling-small-details.py <原图路径> --output <新的空目录>。

## 第二轮布置

新增七处小冰晶、雪堆与散石候选组合，经草区和火盆避让过滤后放入地图；外塔连接段增加两组挂旗/铁链/壁灯，基地补给区追加小绳圈、折叠篷布，过渡段补充格栅与短冰挂。仍不使用零散矮植。

前侧低装饰统一向桥内适当退让，减少加高围栏遮住根部的问题。所有静态小部件按材质合并为 12 个网格；增加摆放数量不会逐个增加渲染调用。保留每批 placements 数据供调试与后续调整。

生产构建及 5 个测试文件共 13 项测试通过。外塔及基地浏览器预览已检查，控制台无错误；截图：docs/visual-validation/2026-10-16/detail-pass2/。
