# 连续围栏 v6

内置 imagegen 重新绘制的加高加宽版本，参考 v5 围栏材质和 04 直墙概念图。原始 RGBA 图保持不变，未进行非等比拉伸。旧版 v5 保留。

提示词：重新设计更高更厚的雪覆哥特石围栏，四柱三面板连续共线，增加两层真实比例的石砖，实墙约加高 30%，墙垛间距约加宽 20%，压顶更厚且有可见顶面。保留冷蓝灰石材、细雕花、少量积雪与短冰挂、左上光照及固定正交视角。透明背景，无旗帜、灯、铁链、植物、地面板和转角。所有细节通过新增砖层与重新构图形成，不拉伸旧图。

运行时沿用每像素 .21 世界单位的统一比例。geometry.json 记录实测脚线、柱体范围及安全拼接裁切范围；拼接只从实体墙面处截断，完整柱帽不会被切半。与旧版相比，实墙像素高度由约 200 增至约 260，柱间原图距离由约 450 增至约 575。挂旗、壁灯与铁链随新的实墙范围下移；地面小冰晶不变。

构建和 4 个测试文件共 12 项相关测试通过，包括 101 种长度的拼接裁切、墙脚支撑、挂件贴墙投影和共享资源释放。固定 45° 中央桥面预览已检查。
