# 中央冰桥：绘制美术与空间构建

唯一美术参考：`assets/map-concepts/howling-abyss-target-v1/04-central-bridge.png`。这次构建的是中央连续桥段，未宣称出生区、防御塔及整张玩法地图全部完成。

## 本轮资源

使用 `imagegen` 技能的内置 `image_gen` 工具生成 4 张真正透明的 PNG；没有购买额度，没有调用外部 Meowa / Meshy / Tripo 付费 API。生成原文件保留，工程文件是原样复制，见 `manifest.json` 的尺寸、透明度与 SHA256。没有把程序几何示意图当成精细美术。

原始提示词见 [prompts.md](prompts.md)。

| 文件 | 用途 | 处理方式 |

| guardian-wall.png | 尖耳兽像、雕花高柱、残损短墙 | 运行时分别按柱和短墙的区域取 UV；原 PNG 不改写 |
| arch-support.png | 拱券、深拱内壁、长承重墩 | 接缝以下取样；保留透明拱洞；长墩覆盖拱段接缝 |

桥面沿用 `howling-target-v2/ground.png`，远景沿用 `howling-central-v1/runtime/depth.png`。桥面地表只投影一次，中央徽记只出现一次；延展部分只使用两端普通砌石，不重复徽记。

## 兽像的位置

兽像本身与它的雕花柱是一个连续资源，安放点以**柱脚**计算，不拿兽像头部或 PNG 左上角当作地图坐标。源码 `PAINTED_PILLARS` 明确记录位置：两侧各六处，沿桥 u=-320、-192、-64、64、192、320，柱心 v=±128；玩法桥宽为 ±112。两侧承重墩与这些 u 值对应，拱跨为 128。源图最近的柱脚角点相对柱心另加 z=20，避免把角点当中心、把柱体挤进通路。

中央桥段地表范围 u=[-340,332]，视觉桥面宽 ±122。柱、墙与桥拱共同搭建，兽像不直接摆在中央地面。该排列是依据预设图结构进行的模块化构建，不是宣称已从概念图恢复了精确三维测量。

## 空间与运行时

固定 45° 正交视角；主要素材不会每帧转向相机。网格从源图的落脚线估计柱面、侧面和高度，参与真实深度测试及 alpha 测试投影。它是固定视角的近似深度，并非完整可旋转模型。

桥面使用独立地面网格、薄边和阴影接收层；桥拱位于桥下，拱洞透明。远景有独立世界位置。角色沿用真实 Match 与角色动画，靠近前景柱时，仅遮住英雄的那根柱局部淡出，暂停冻结、重开恢复。静态栏墙合批，保留兽像柱的独立遮挡控制。

## 项目内比较结论

- 本轮内置生成的兽像柱有尖耳、鬃毛、正确坐姿、可见侧面及细密石刻，比已有正面 Meowa 栏墙更适合当前相机，采用本轮版本。
- 旧 Meowa 栏墙仍有可用的绘制细节，但它是不同构图的旧任务，缺少兽像且存在半透明环境底；本轮不使用它作主栏墙。不是用一次不对等比较断言服务优劣。
- 上轮本地程序 3D 造型规整、雕刻简单，淘汰。Skill 仅提供流程，不能代替资源和实机的质量检查。
- [对照页](index.html)展示参考、原素材和本轮资源；实机检查记录在 `docs/visual-validation/2026-10-16/painted-sample-v3/`。

当前仍可看到模块重复；火焰图案是静态绘制，动态仅作用于地面暖光。装饰没有新增玩法碰撞。完整场景美术仍需用户验收，不把构建或测试通过当成风格通过。
