# 装饰小雪兽 v1

使用项目 game-assets Skill 通用生成一张六姿态素材表，再用本地组件拆分工具无损拆分；源图保留在 generated，最终运行时文件为 components/component_001.png 至 component_006.png。六个姿态分别为站立、眨眼、迈右脚、迈左脚、嗅探和蜷缩。

实际尺寸分别为 299×274、295×274、299×268、296×270、293×279、298×202，均为 RGBA、透明边缘，无拆分警告；按最近邻在实际游戏约 39 世界单位宽度呈现。不宣称原图是固定 64/128 像素逐帧角色动画。

只生成一只场景装饰动物，家与探头点均在中段上侧草丛轮廓内，短距离往返不经过桥中央。初始隐藏 9 秒；安静时缓慢探头、嗅探约 2.6 秒后退回，随后隐藏 18–30 秒。移动单位靠近家 180 或自身 150 世界单位时加速退回，持续靠近会延后出现，至少安静 12 秒才可能再探头。

进出与嗅探通过独立装饰扰动带动附近草叶弯曲、积雪抖落；不触发英雄遮挡透明度或玩法逻辑。身体渐显／渐隐并由前层草叶自然遮挡，隐藏时身体和阴影均不可见。不新增敌人、碰撞、目标选择、生命值或战斗事件。

状态以模拟时间更新；暂停不推进，重开复位，“小雪兽”开关和“动态地图”总开关可关闭显示。
