# 亚索吹箫

源文件：`assets/source-materials/heroes/yasuo/亚索吹箫.webp`。通过 `python scripts/import-yasuo-flute.py` 将全部 32 帧逐像素保存为 8×4 图集，单帧 64×113，125 ms/帧；保留透明度、源色彩与全部帧。脚底锚点 (32,108)，世界比例 0.25，与英雄动作保持一致。源 SHA-256、逐帧边界与时序见 animation.json。

游戏中 Ctrl+3 开始动作；4 秒动画与 6.3 秒音轨分别持续循环，不再自动结束。移动、攻击、施法、S 停止及任何有效伤害都会取消。施法、攻击前摇、受击硬直、击飞、死亡和非比赛进行状态不能开始吹箫。暂停冻结动画并停止声音，继续时从当前动作时间恢复音轨。关闭声音仅停止声音，动作仍可播放。

快捷键、动作生命周期、打断、动画帧时序与音频偏移已测试；浏览器实际 Ctrl+3 已确认显示“亚索 · 吹箫”与对应角色动作。截图：`docs/visual-validation/2026-10-15/yasuo-flute.png`。音频采用用户 MP4 中的原音轨，处理记录见 assets/audio/yasuo-user-v1/manifest.json。

快捷键兼容：部分浏览器或应用会在页面收到按键之前用 Ctrl+3 切换标签页，此时页面无法阻止。游戏支持单按 3（含小键盘 3）和“选项 / 练习”中的“吹箫 · 3”按钮作为可用入口；转发到页面的 Ctrl+3 会在捕获阶段处理。暂停或未开局时会显示提示。
