# 疾风对决 0.1.1 动作与声音修复

2026-10-21。修复范围仅为疾风对决目录，完整原项目未修改。

1、2、4 的动作图集、注册数据及语音资源均存在，故障来自装备栏在 Three.js 入口的 document 捕获阶段拦截数字键。原版入口在 window 捕获阶段处理表情，因此两个入口此前还存在按键优先级差异。

现统一保留 1 玩笑、2 嘲讽、4 笑声及 3 吹箫；装备前两格使用 Alt+1、Alt+2，其余四格保留 5、6、7、8，饰品使用 Alt+4。仍可右键装备栏使用主动。HUD、操作指南和 README 已同步更新。

语音改由已确认的动作状态触发，每次动作只触发一次，移动和受击打断，继续保持五秒语音防刷冷却。联机不再在服务器确认前播放表情语音。原版入口在开始战斗前准备音频，修复冷启动第一次表情可能无声的问题。

核查精简清单中 784 项保留资源，均与完整项目逐字节一致，无缺失；精简前后代码仅有启动及桌面联机适配差异，没有发现其余代码被删。

验证：183 个测试文件、1,019 项测试通过；TypeScript、Vite 生产构建、服务端类型检查通过；两个入口分别验证三个表情的持续动画帧、实际语音启动、S 打断、装备快捷键和搜索框输入隔离，无脚本异常或失败资源请求。Windows 包验证双实例联机、客机刷新恢复、主机退出清理、单人加载，无异常。联机测试在同一台电脑进行，不代表两台实体电脑的防火墙环境测试。报告见 audit/emote-fix-verification.json。

新版包：release/疾风对决-0.1.1-Windows-x64.zip；程序：release/疾风对决-0.1.1-win32-x64/疾风对决.exe。旧版本运行目录被占用，故采用包含版本号的新目录。请退出旧版后使用新目录，联机双方均使用 0.1.1。
