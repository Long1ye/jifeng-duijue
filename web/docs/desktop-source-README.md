# 疾风对决

从同级 `pixel-league-of-legends-V2` 独立复制并精简的网页游戏项目。原项目未修改。保留现有 Three.js 冰桥、原版游戏入口、单人 AI、局域网对战、装备、技能、动画、音频和自动化测试。

按 `1 / 2 / 4` 播放玩笑 / 嘲讽 / 笑声动画与语音，`3` 吹箫；移动、施法或受击会打断。装备前两格改用 `Alt+1 / Alt+2`，其余四格为 `5 / 6 / 7 / 8`，饰品为 `Alt+4`，也可右键装备栏使用。

操作指南已改为鼠标手势图和按键卡片：鼠标与镜头、战斗与装备分组查看，1～4 的动作与声音分别说明。可点击手册标题收起。

## 启动

### Windows 游戏包（无需 Node.js）

完整免安装包位于 `release/疾风对决-0.1.2-Windows-x64.zip`。解压整个压缩包，双击 `疾风对决.exe`。不要只移动 exe，运行时依赖同目录的 DLL、资源和 `resources/app.asar`。

- 主机点击“创建对局”，将启动器显示的局域网地址（含端口）以及游戏窗口中的六位房间码告诉好友。
- 好友运行相同版本程序，填写主机地址和房间码，点击“连接并加入”。双方资源加载完成后点击准备，倒计时开始。
- 首次主持时允许 Windows 防火墙的“专用网络”访问。默认端口 5180，占用时自动尝试 5181–5190，以启动器显示为准。
- 两台电脑使用同一 Wi-Fi 或有线局域网；不需要账号、互联网、公网服务器或额外的 Node.js。仅接受本机 / 私有 IPv4 主机地址。
- 主机关闭整个程序或点击“停止主持”会结束对战。只关闭游戏窗口时主持服务继续运行，可在启动器重新进入。
- “单人练习”在本机运行 AI 对局。游戏窗口顶部“游戏 → 返回启动器”可返回地址分享界面。

平台上传时将 ZIP 内容直接放在包根目录：可执行文件填 `疾风对决.exe`，启动参数留空，版本号填 `0.1.2`。配置和压缩包 SHA-256 见 `release/upload-config.json`。这是 Windows x64 免安装目录包，不是安装向导；可执行文件尚未进行代码签名。

重新构建：`npm ci` 后执行 `npm run package:win`，会生成游戏网页、独立对战服务、Windows 程序和上传 ZIP。桌面包自带 Chromium 与 Node.js 运行环境，其体积高于下面的纯网页资源包。

当前 0.1.1 修复及检查见 [动作与声音修复记录](docs/emote-fix-0.1.1.md)。本次 Windows 封装通过 1,019 项测试及打包 exe 的双实例局域网对战、重新进入后的恢复、主机退出清理和单人加载验证。完整配置与验证说明见 [Windows 局域网发布包](docs/windows-lan-package.md)。

### 网页开发入口

依赖已安装，可直接双击根目录的 **启动局域网对战.vbs**，或使用 Node.js 24+ 在本目录执行：

```sh
npm run dev:lan
```

打开启动器显示的局域网网址。单人也可使用同一个游戏菜单。

本机开发：`npm run dev`，打开 `http://127.0.0.1:5173/three.html?map=howling&scene=match`。根页面保留原版入口。

## 构建与验证

```sh
npm test
npm run check:server
npm run build
npm run preview
```

生产文件位于 `dist/`，默认构建仅包含两个游戏入口。`npm run build:share` 输出同样的游戏到 `dist-share/`。静态包用于单人试玩；局域网联机仍需运行 `dev:lan` 服务。

新项目拥有独立安装的依赖，没有指向原项目的目录链接；以后重新安装可执行 `npm ci`。
