# 低配模式与自动画质

修改项目：`D:\Long1ye\疾风对决网页版`。设置 → 视频 → 性能模式，即时生效并保存在当前浏览器。

| 模式 | 16:9 分辨率上限 | 绘制帧率上限 | 环境/视觉迷雾更新 | 实时阴影与迷雾 MSAA |
| --- | --- | --- | --- | --- |
| 高清 | 1920×1080 | 60 | 30 Hz | 开 / 4 samples（设备支持时） |
| 均衡 | 1600×900 | 60 | 15 Hz | 关 / 关 |
| 低配 | 1280×720 | 30 | 10 Hz | 关 / 关 |
| 极低配 | 640×360 | 30 | 8 Hz | 关 / 关 |

小窗口按 CSS 尺寸渲染，不额外放大；竖屏和其他比例同时受像素预算与宽度限制。相机仍使用完整视口比例，鼠标选取和世界坐标不随降分辨率变化。血条、技能栏等 HUD 使用原来的独立界面层。

自动模式在开始对局时使用游戏已有 WebGL 上下文检测当前渲染设备。软件渲染（例如 SwiftShader、llvmpipe、Microsoft Basic Render Driver）预设极低配；核显/集成图形预设低配；独显特征预设均衡，部分已知性能较强的 RTX/RX 型号配合至少 8 个 CPU 逻辑线程、足够内存及纹理上限时预设高清。CPU 不超过 4 线程或浏览器报告内存不超过 4 GB 时至多低配。纹理上限只能限制档位，不作为性能强的依据。

浏览器屏蔽显卡信息或型号未知时使用低配。这里只能推断浏览器当前使用的渲染设备，不能完整枚举整机显卡，也不能可靠判断双显卡机器是否另有一张未被使用的独显。型号只在本地用于一次启动分类，不上传、不持久保存原始型号。自动模式继续记住已降低的档位，保存的档位不能覆盖更弱的硬件预设；手动画质保持用户选择。重新选择自动模式会按本次检测结果重新预设，并恢复持续掉帧降档。

自动策略读取 RAF 间隔，与 30 FPS 绘制上限独立。加载结束、恢复运行或切换设置后有 3 秒预热；连续两个 2 秒统计窗口低于阈值才降低一档。高清/均衡阈值为 40 FPS，低配为 24 FPS。隐藏页面、暂停、非对战阶段不参与采样，超过 250ms 的孤立长间隔不参与采样。当前会话不自动升档，避免画质来回跳动；可手动选择高清或其他档位。调整精度、环境画质或增强细项会进入自定义模式并停止自动降档，选择自动可重新启用。

低配保留接地暗部、角色落地阴影和轻量调色，关闭环境风雪、动物装饰、晶尘、冰雪附加层和建筑光晕等；均衡进一步保留材质细节与建筑光晕。低配/均衡/高清的环境纹理各向异性采样上限分别为 2/4/8，受设备上限限制。低配像素预算约为高清的 44%，同时维持 30 帧绘制上限。角色动作、普攻、技能、伤害提示和音效保留。装饰动画按档位降低更新频率，角色和技能仍按实际对局时间采样。极低配保留 640×360 作为严重卡顿和软件渲染的保底。

2026-10-23 后续反馈修复：小兵血条改为与英雄/防御塔一样的独立 UI 画布，不参与低分辨率世界渲染；血条对齐设备像素，血量不变时复用已绘制内容，原有世界内血条隐藏，避免细线在缩放中闪烁。敌方可见性、死亡移除和伤害数据仍按原有逻辑执行。

点击开始游戏后先显示画质说明，告知自动模式优先保证流畅，以及通过“设置 → 视频 → 性能模式”切换均衡/高清；说明保留已保存的手动设置。确认后才开始进入游戏，返回或 Esc 可关闭提示而不进入对局。

本轮回归：190 个测试文件、1061 项测试通过，普通构建、平台构建及服务端类型检查通过。浏览器确认低配 1280、均衡 1600 和部分增强项切换正确；实际兵线已创建独立的 34×5 CSS 像素小兵血条，移动位置对齐设备像素，控制台无错误。提示弹窗的 Esc 返回、重新打开及确认进入已验证。未进行目标核显硬件帧率对比或宣称所有设备均能稳定达到绘制上限。

绘制限帧位于 ThreeArena 内，发生在团队视野判定和战斗事件消费之后。跳过绘制时仍调用 onFrame，保留音效/HUD/交互回调。PrototypeHost、NetworkHost、服务器、伤害、碰撞、技能冷却及联机协议没有改动。视觉迷雾纹理降低更新频率，TeamVision 的敌人可见性判定保持每次更新执行。

主要实现：`GraphicsPerformance.ts` 管理档位、设置验证、采样和绘制节奏；`ThreeArena.ts` 管理渲染开销；`WarFog.ts` 支持关闭离屏 MSAA，并只在采样数变化时重建附件。WebGL 主画布启动时关闭 MSAA，高清的迷雾离屏缓冲仍可使用 MSAA。

回归测试覆盖持续掉帧、孤立卡顿、暂停/隐藏、手动覆盖、设置读取、30 FPS 节奏、不同视口像素预算、迷雾附件重建，以及跳过场景绘制时战斗结果与原始 60Hz 模拟一致、事件和回调不丢失。实际核显设备上的帧率需要目标机器验证，不能仅凭开发机结果承诺。

2026-10-23 验证：187 个测试文件、1042 项测试通过；普通构建、平台构建和服务端类型检查通过。浏览器确认低配/极低配/高清即时切换；568×884 小窗口的极低配内部画布为 384×598，HUD 独立显示。平台静态服务 HTTP 200，页面包含新性能设置。截图：`.cache/performance-qa/low-settings.png`。
