# 地图兵线节奏方案

2026-10-20。适用于正常单人和联机对局（`league:true`）。

原配置将端游小兵移速 350 按技能距离比例 `145/475` 换成约 106.8 世界单位/秒，25 分钟后达到约 137.4；这一比例没有考虑地图的实际行军距离。当前冰桥前排出生位置到中线约 2379.5 世界单位，原配置只需约 22.3 秒即可走完，后期还会进一步缩短。

本轮以可读的行军节奏为目标，设置以下初始试玩参数。这里的 55 秒是设计目标，仍需玩家反馈确认。

| 参数 | 当前冰桥 | 森林小地图 |
| --- | --- | --- |
| 世界尺寸 | 6200 × 3400 | 1022 × 654 |
| 前排出生位置到中线 | 2379.5 | 304.3 |
| 小兵移速（世界单位/秒） | 43.26 | 24 |
| 无阻挡走到中线 | 55 秒 | 12.68 秒 |
| 出兵间隔 | 36 秒 | 24 秒 |
| 无阻挡相邻波前排间距 | 1557.5 | 576 |
| 首波生成时间 | 开局 2 秒 | 开局 2 秒 |
| 每波组成 | 3 近战 + 3 远程 | 3 近战 + 3 远程 |

以双方前排出生锚点之间直线距离的一半作为行军距离 `D`，不以整张贴图宽度计算。测量和实际生成共用 `minionWaveFront`，后续修改出兵位置或桥身长度时会重新计算。

- 移速 = `clamp(D / 55, 24, 44)`。上限控制画面中的移动速度，下限避免小地图的小兵过于缓慢。
- 实际行军时间 `T = D / 移速`。
- 出兵间隔 = `clamp(round(T × 0.65), 24, 40)` 秒。冰桥在上一波尚在行军时发出增援；短地图保留至少 24 秒间隔，避免高频堆兵。
- 近战和远程采用相同速度，行军和接敌不额外加速。时间成长不再提高移速；生命、攻击等原有成长仍生效。
- 首波生成、暂停、重开和双方同步沿用比赛模拟时间。训练／旧原型（`league:false`）保留其原有节奏。

行军时间是假设无阻挡走到几何中线的测算值，不是首次攻击时间。射程、索敌、阵型、建筑绕行和英雄干预都会改变首次交战时刻。回归测试检查两张地图自然交战、连续出兵间隔、30/60/120Hz 位移一致性、后期移速稳定、暂停与新局；试玩时继续观察补刀窗口、清线后空档、推线增援和长期堆兵，再调整 `MINION_PACING_RULES`。

实现位于 `src/game/MinionPacing.ts`，通过 `LaneStats` 和 `Match` 同时作用于实体移动、阵型推进与出兵计时。
