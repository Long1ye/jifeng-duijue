# 嚎哭深渊地图美术目标 v1

2026-10-16。用户要求先生成精美的纯游戏地图画面，作为后续资源制作依据。本轮暂停继续叠加地表实现，先统一目标画面；不扩大可玩全图。

状态：用户认可出生区和中央桥段的美术方向，称其为理想游戏实景；外塔图不采用，原因是像纪念碑，需要更明确的战斗防御塔。后续[中央接入01](visual-validation/2026-10-16/threejs-P2-central-01/README.md)已据中央图制作6个独立部件并进入实验场景，仍待实机验收，不是全图量产。每张目标图实际2048×1152，不透明PNG，复制字节与原图一致，哈希见[manifest](../assets/map-concepts/howling-abyss-target-v1/manifest.json)。目标稿本轮净消耗46积分，余额670→624；首次出生区失败已退12积分，随后一次重试成功。

## 图像契约

- 主题：嚎哭深渊，古老弗雷尔卓德冰桥、石构遗迹、雪、薄冰与深渊；不转为森林或另一张暗黑地图。
- 画风：参考Eldest Souls的厚重石构和像素层次、Hunt the Night的材质与氛围；原创场景构图，不复用原作素材。
- 交付：一张连续场景总览，以及出生区、蓝方外塔、中央桥段三张独立局部目标图。纯环境，无人物、HUD、文字或图板标注。
- 相机：高俯角正交游戏视角。图像是美术候选，不是当前运行截图、精确可走地图或已能直接切分的生产图集。
- 原图：Meowa通用生成Image2.5、2K档、16:9、Detailed；下载后核对实际尺寸，不缩放、裁切、调色或再像素化源图。

## 设计重点

| 区域 | 视觉职责 | 后续资源拆分方向 |
| --- | --- | --- |
| 出生区 | 庇护感与阵营识别；古老祭台、冰晶、残损石柱、厚雪包边 | 祭台、柱体、阵营晶体、平台铺装、雪边与冰缘 |
| 外塔 | 建筑与地面完整连接；塔周放射铺装、守卫石雕、修补路面 | 塔体分层、基座、雕像、石板变体、修补块和石屑 |
| 中央桥段 | 开阔可战斗空间与深渊纵深；残损刻纹、桥沿、冰雪侵入 | 直/转/破损栏墙、支撑结构、刻纹残片、多地表过渡 |

主通道保持大面积可读的石面，细节向桥肩与建筑周边聚集。薄冰和积雪应形成连续、有风向与遮蔽原因的侵入边缘，不随机混铺方块。火盆只作为少量暖色点缀，冰冷环境主导色调。

## 目标图到生产资源

先审阅四张图的主题、构图、材质丰富度和画面层次，再选择采用部分。以采用图建立共用色板、纹素密度、相机、模块与过渡规格，随后分别生成地表变体、过渡图集、建筑与装饰；在S01验证接缝、比例和角色可读性后继续迭代。不能从概念图漂亮直接推断运行效果或宣布P2通过。

通用生成的像素表现仅用于方向参考，不保证严格像素网格。后续制作时不能直接把高分辨率目标图缩小，冒充已规范化的像素资源。当前是部分目标图已获方向认可，实机尚未验收；不宣称已经匹配两款参考游戏的全部特征。

一致性问题：总览中的外塔偏石质火盆塔，而外塔局部图采用持冰晶守卫塔。两者是候选方向，不能同时当作已冻结的同一资产；选择后需要回到统一塔型、装饰与周边铺装规范。共用参考有助于色调和环境一致，但不保证不同生成图中建筑身份完全一致。

用户后续明确：持冰晶守卫塔像纪念碑，不采用为正式外塔。下一版应为更紧凑、攻击功能清晰的战斗防御塔：厚重低基座、可辨认的攻击冠部/发射结构、受约束的冰蓝能量核心；人物雕像如保留，只能作为环境装饰，不能替代防御塔身份。主题仍是嚎哭深渊，不引入科幻炮台。
