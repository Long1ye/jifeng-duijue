# 场景动态修订：重做火焰、塔与冰晶

本批后续收到五张截图反馈：墙上火仍静态、冰晶暗且红晶体混蓝、塔旗不明显、火盆穿插。下面保留为第二批历史记录；最新代码与对应位置预览见 [反馈修复](../motion-feedback/README.md)。

用户反馈第一批效果差、火焰不真实、塔变化不明显、冰晶看不出变化。本批接受该反馈，原技术测试通过不等于视觉通过。

[打开修订预览](http://127.0.0.1:5173/docs/visual-validation/2026-10-19/scene-motion-v2/motion.html)。可切换“本轮修订 / 上轮记录”，以及桥面、靠墙两个镜头；暂停后切换版本保留采样序号。每组 48 张、16 张/秒、3 秒循环，45°、正常缩放 0.6、1600×900。镜头和单位固定，仅推进环境时间。上轮为历史截图，不能代替当前代码中的严格逐项 A/B，也不是实际游戏帧率录像。

## 本次实际变更

- 火焰：取消原顶部摆图和静态火形光晕；仅在原图火舌范围内抑制暖色像素，保留石碗、木炭和光照。新增一个实例化绘制批次，五股独立高度的火舌共享向上平流的连续噪声，产生弯曲、分叉、断裂和消散。属于风格化程序火焰，不是流体仿真或预渲染真实火焰素材。
- 塔：核心材质有明确的明暗流动，颜色遮罩进一步限制在塔顶晶体；新增沿核心运行的短弧和少量微光。原图左右挂旗按 UV 区域做旗尾形变，杆端保持固定，塔身和碰撞不动。红蓝均保留原色和攻击蓄能。
- 冰晶：不再仅在亮部微加白色；对彩色晶面同时调整暗部与亮部，让光带移动有可见对比。增加少量缓慢升起、环绕的微光，放到表面前方，避免被自身深度遮掉。底座不摇动。
- 边缘：新火焰轮廓、晶面光带与短弧采用 `fwidth` 平滑，保留既有 MSAA、透明边缘覆盖和采样设置，不加入 TAA 或整屏模糊。微光使用连续衰减形状。

使用比赛模拟时钟，不增加独立计时器。暂停固定、重开恢复；死亡/隐藏的塔及未加载的物件关闭对应微光。轻量档关闭微光与短弧，保留基本火焰。成熟战斗、声音、伤害与输入规则沿用原逻辑。

成本：新增两个批次（全部火焰一个实例化网格；全部微光和短弧一个 Points），无新纹理、源图片或渲染目标，同时移除火盆旧静态形状光晕绘制。塔旗复用既有 relief 顶点。微光数量固定，无逐帧新增对象；资源单独释放，不释放借用的原图或源几何。不将这些短时检查外推为全设备 FPS 保证。

## 验证与边界

- 142 个测试文件、789 项通过，`--maxWorkers=2 --testTimeout=30000`。此前与浏览器并行的全量运行中，既有兵线长模拟超时；该用例单独通过，随后限并发全量通过，未修改模拟规则或项目全局超时。
- TypeScript / Vite 构建通过。
- [GPU 与相机报告](report.json)：八组动态隔离检查通过，重复同一模拟时间的差异均为零；shader 编译无错误。
- 正常缩放下隔离冰晶在 2～2.35 秒有 8281 个像素变化超过 2/255，最大差 65/255；塔组同时包含旗面形变。像素指标仅证明变化生效，视觉认可仍待试玩。
- 1280/1920、0.4/0.6/1.5 缩放下平移相机再回到原位置：无超过 2/255 的残留差异，最大差 1/255，地面拾取误差小于 1e-6。硬件抗锯齿启用。这是复原及拾取回归，不证明所有中间移动帧都没有闪烁。
- 五次重开均为 141 个几何、34 张纹理，无持续增长。
- [战斗与声音回归](combat/browser-report.json)记录正常输入、技能/音频、暂停及重开。结果以本批新报告为准，不引用第一批替代本次结果。
