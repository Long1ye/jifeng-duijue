# 防御塔统一内塔尺寸

红蓝两侧共八座塔统一使用内塔原有 .78 的展示比例。移除双守卫塔 .53 和外塔 1.0 的独立比例，外塔铺地直径同步改为内塔的 150；点击代理随展示比例缩小。

角色遮挡淡化的轮廓宽高改为乘实际 mesh.scale，防止塔外侧仍按旧的大轮廓触发淡化。建筑保留 alphaTest、正常深度测试与深度写入、独立透明轮廓的阴影深度材质；英雄确实被挡住时仍沿用原有淡化机制。

实机复查圣所双塔与雕像、围栏、水晶的层次，以及外塔与火盆、围栏、草丛的相对位置。截图 sanctuary.jpg、outer-tower.jpg。

验证：相关两个测试文件、9 项测试通过，包含八塔统一比例、按实际尺寸选择和遮挡触发边界；生产构建通过，浏览器错误日志为空。
