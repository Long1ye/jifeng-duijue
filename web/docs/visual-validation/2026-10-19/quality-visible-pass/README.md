# 第二轮：实际游戏尺寸下的材质和环境光

用户反馈上一轮优化不明显。本轮继续原画质清单 Q04、Q06、Q09；上轮证据保持原样。

本轮改变：

- 石板纹理的明暗分离强度 0.34、线性亮度中点 0.22，沿用原图中的石缝、板面和积雪；微法线仍保留，但不把它当作本轮主要改善。
- 建筑沿用原图明暗，阴影面至多乘 0.83、亮面至多乘 1.06；既有晶体与团队色 shader 继续组合。
- 火盆实际位置半径 215、壁灯布局半径 155，强度 0.62。世界空间三维距离平方衰减，连续影响环境表面；不增加 PointLight、影图、绘制调用或渲染目标。是风格化照明，没有新增逐光源遮挡计算。
- 峡谷远景空气透视混合从 0.025 提高到 0.20，维持原视差、低雾与背景资源。

## 验证

- `npm test -- --reporter=dot --maxWorkers=2`：135 文件，741 测试通过；新增环境光父级隐藏、模拟时间冻结和排除战斗对象的检查。
- `npm run build`：通过。
- [生产包冒烟检查](production-report.json)：独立预览构建产物，实际 Q/W 输入、轻量档、画质对照和暂停通过；零页面错误、零资源失败、单画布，26 个音频文件成功加载。
- [浏览器报告](report.json)：Chrome，视口 1600×900，内部 1920×1080；零浏览器错误和资源请求失败。平移、1280/1920、三档缩放、地面拾取、暂停和五次重开通过，模拟实体没有被画质代码修改。
- 同镜头调用数中央基础 82 / 优化 69、外塔 85 / 76、圣所 99 / 94，与上轮一致。新增的是片元着色计算，不能由「未增调用」推导零开销。
- 静态圣所每档 10 帧预热、45 帧采样，`host.update(0) + gl.finish()` 的中位数基础与优化均约 0.9ms，P95 均约 1.1ms。包含同步开销，只代表当前机器静态样本，不是正常交战 FPS 或低端设备保证。
- 独立关闭材质细节后，圣所最大通道差 61/255（上轮同类检查 1/255）；该数字仅用于确认响应强度，不能替代正常尺寸视觉判断。
- [战斗和声音报告](combat/browser-report.json)：Q/W/Q3/R/EQ3、护盾、闪现、塔毁坏和普通输入回归通过；存在真实可测声音输出，五次重开稳定为 97 几何体、42 纹理。没有更换音效或技能素材。

## 回退与后续

游戏「画质细项 → 材质细节」关闭本轮石材/建筑响应与环境暖光；「环境调色」关闭远景调节；「画质对比 → 基础」关闭全部新增画质效果。原有战斗与音频不受这些开关影响。

Q04/Q06/Q09 在主文档保留「待视觉确认」。如果试玩仍不满意，沿同一条目和同镜头继续调整，不再仅凭测试数量或非零像素差异宣布画质完成。
