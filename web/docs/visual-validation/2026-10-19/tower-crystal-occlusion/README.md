# 悬浮水晶与石尖深度冲突修复

2026-10-19。用户截图指出水晶下缘和前方石尖出现闪烁穿插。本轮已复现并修复，观感待确认。

根因：水晶从同一份浅浮雕网格复制，悬浮时仍与塔身共享近乎相同的深度面。浮动和横向轻摆让重叠片元交替通过深度测试。不是塔旗拉扯问题。

修正：水晶独立网格沿固定 45° 视线向后退 8 个局部单位（Y、Z 各 -8），使它稳定处于前方石尖之后。等量 Y/Z 偏移保持当前 45° 投影位置；原悬浮高度、幅度、横摆、颜色、石座和旗帜都保持。保留正常深度测试，未使用强制覆盖绘制次序。该投影不变结论针对游戏的固定 45° 镜头，其他候选仰角未进行本轮视觉验证。
