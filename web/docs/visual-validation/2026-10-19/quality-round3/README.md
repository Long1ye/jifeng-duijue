## 验证结果

- `npm test -- --reporter=dot --maxWorkers=2`：135 文件、743 测试通过。新增光源随父级移动、不同高度连续衰减、隐藏源关闭，以及三层雾共享开关和停表检查。
- `npm run build`：通过。
- [浏览器画质报告](report.json)：零页面/着色器错误、零资源请求失败；五组专项均有实际输出变化；暂停、三档缩放、1280/1920、镜头平移、地面拾取和模拟数据不变检查通过。
- 接缝专项：在本次峡谷镜头中，将完全雾化后的桥墩与隐藏桥墩后的真实背景比较，1263 个投影样本最大通道差 **0/255**。这个结果只证明本镜头和所采样区域的背景匹配，不外推到任意视角。
- 暂停专项：模拟时间保持 1/60 秒。火盆、壁灯、红晶和峡谷两帧逐字节一致；蓝晶仅 1 个像素变化 1/255。报告保留原始计数；脚本只容许最多 8 个像素、每通道最多 1/255 的量化差异，不把它当作动画继续运行。
- 五次重开稳定为 143 几何体、36 纹理。该统计在访问新增专项镜头后采样，不能与只访问三个旧镜头的资源计数直接相减；本轮没有新增地图/角色贴图或渲染目标。
- 静态圣所各档预热 10 帧、采样 45 帧，`host.update(0) + gl.finish()`：基础中位约 1.1ms、优化约 1.0ms，P95 均约 1.5ms。差异属于当前机器短样本波动，不能推导优化提升 FPS。三个原固定镜头绘制调用与上轮一致；额外成本是角色的片元照明计算。
- [战斗与音频回归](combat/browser-report.json)继续保存技能、护盾、召唤师技能、塔毁坏、普通输入、可测声音输出和重开资源检查；[生产包报告](production-report.json)检查构建产物的实际输入、轻量档、画质开关和暂停。
