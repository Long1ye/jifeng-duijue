# Three.js 战斗表现迁移与环境融合

日期：2026-10-19。用户要求复用已有成熟战斗特效、音效，再落实 Three.js 场景提升策划。

## 入口与操作

- 正常对局：`/three.html?map=howling&scene=match`，Three.js 页默认进入此模式。
- 固定靶：`/three.html?map=howling&scene=combat`。
- Q/W/E/R、D 闪现、F 点燃、3 吹箫、S 停止；右键移动或攻击。Y 切换跟随。
- 声音首次点击或按键后解锁。音效与音乐默认开启；环境声音默认关闭，可单独开启。
- 环境画质「轻量」关闭飘雪和实时建筑阴影，保留战斗特效、角色地影、技能规则与音效。画面精度仍可独立调整。

根页面和分享构建保持原有入口，本轮没有发布或将 Phaser 根页面替换为 Three.js。

| 原有成熟内容 | Three.js 接入方式 |

| E | 复用原 E 角色动画、三段残影、尾迹与目标锁定倒计时；倒计时前后弧围绕身体 |

`PrototypeHost` 仍是唯一事件取出方；同一个事件批次分发给画面和音频。伤害、碰撞、冷却、控制、连招及比赛规则没有为美术迁移另写一套。声音和残影在暂停、切出窗口、重开与销毁时清理，恢复风墙时按实际存续年龄重建持续声。语音和吹箫继续压低 BGM。

## 环境提升

- 角色暖色染色改为当前地图实际火盆位置，保留原团队基色；固定太阳方向下增加柔和的角色遮阴近似，强度上限 10%。它是表现近似，不是读取 GPU 阴影贴图。
- 击飞高度复用原 `airborneLift`，脚底阴影随高度变淡、扩散，并平滑恢复。
- 飘雪共 240 点，分布偏向桥边；草丛、旗帜、雪和火星共享原 `environmentWind` 的风向与阵风公式。
- 远景随镜头移动形成较慢视差，三层低雾采用不同移动比例。桥墩雾化采样同步到实际远景纹理尺寸与位移。
- 冰晶及建筑水晶在原绘制颜色上增加克制的亮边与呼吸变化；可交战防御塔读取真实前摇、攻击释放状态增强能量。
- 防御塔摧毁后显示使用已有石材纹理的确定性残骸，重开恢复。残骸碎块使用实例化，避免逐块增加绘制调用。
- 新增出生区实际恢复时的脚底提示。不增加技能、投射物的动态照地光。

图集共享、卡片与 E 残影复用；命中线条合并到一个动态几何批次，仅上传已使用的缓冲区。特效图集提前请求，避免第一次施法时才开始下载。

## 验证与证据

- `npm test -- --reporter=dot --maxWorkers=2`：134 个文件、735 项测试通过。
- `npm run build`：TypeScript 与生产构建通过。
- `node scripts/validate-three-combat.mjs`：真实 Chrome/WebGL 中检查原图集尺寸、Q、W、Q3、R、EQ3、护盾、点燃、闪现、正常键盘输入、轻量档、暂停及五次重开。控制台错误与失败请求均为空。
- `npm run preview -- --port 4179` 后执行 `node scripts/smoke-three-production.mjs`：构建产物实际运行，Q/W、画质切换、暂停与音频资源加载通过，只有一个游戏画布，无错误及失败请求。
- 音频检查：最终运行加载 30 个音频资源，追踪 15 次缓冲音源启动，Q、命中、W、龙卷、R、EQ3 六个采样点测得非零音频输出；包含风墙循环声。此项验证实际输出链，不替代主观听感验收。
- 五次重开在已加载样本区域稳定为 98 个几何体、43 张纹理；没有随重开持续增长。
- 局部火盆场景，1920×1080 内部分辨率，短时无头 Chrome 采样：完整档 76 次绘制，轻量档 55 次绘制。采样仅用于本场景比较，不代表全图、密集兵线或全部设备达到某一 FPS 指标。细项见 `browser-report.json`。

首次默认并发全量运行出现一项兵线测试超时；单独重跑通过，限制两 worker 的全量运行通过。同期桥拱接缝调整的旧断言已由对应工作同步；本轮保留该场景调整。
