# 小魄罗首版接入

按“蓝方圣所一对、中段一只”方案接入，素材参考现有 15-sanctuary-crystal-poros 概念图生成。三个最终透明 PNG 保持原生裁切尺寸，没有将概念图里的角色直接当作成品。

素材：assets/map-modules/howling-poros-v1/ 下的 poro-sleep.png（196×173）、poro-alert.png（188×195）、poro-curious.png（184×204）。每张均为 RGBA，已核对独立轮廓和透明背景；本地素材页 index.html 以原生尺寸预览。

摆放：圣所趴睡魄罗 u=-603、v=-117，站立伙伴 u=-591、v=-111；中段歪头魄罗 u=26、v=-97。高度约为英雄的三分之一，避开功能草丛和主路，使用灰蓝色调和独立贴地阴影。

MapPoros 只属于美术场景，不注册实体、碰撞、血条或点击目标。首版提供脚底固定的轻微呼吸，站立伙伴每 21 秒有一次小跳；不含投喂、跟随或生成逐帧动画。暂停和重新开局使用已有游戏时间，独立纹理加载错误接入场景状态，资源随场景释放。

已在实机 45° 镜头复查圣所与中段；截图 sanctuary.jpg、central.jpg。相关 2 个测试文件、7 项测试通过；TypeScript 和 Vite 生产构建通过，浏览器错误日志为空。
