# 场景动态第一批：火、布、草与核心

后续反馈：用户认为本批火焰不真实、塔动态偏弱、冰晶看不出变化。以下保留为第一批历史记录，不能当作视觉认可；最新修订见 [第二批](../scene-motion-v2/README.md)。

目标从继续堆叠静态画质改为“正常游玩时场景持续有生命感”。计划与剩余事项统一维护在 [画质路线图 M01～M08](../../../threejs-quality-roadmap.md)。

[打开连续动态查看器](http://127.0.0.1:5173/docs/visual-validation/2026-10-19/scene-motion/motion.html)：桥面和靠墙两个镜头可切换，每组 48 张、16 张/秒、3 秒循环。固定 45°、缩放 0.6、1600×900，镜头和单位静止，仅推进环境模拟时间；这里的截图采样速率不是游戏帧率。可暂停观察旗顶、草根和石体是否稳定。

## 第一批实现

- M01：火焰顶部按源图 UV 限定范围形变，暖色火内明暗流动；火盆地面/墙面光晕与环境受光增加双频起伏。石碗不整体摇动，不生成新火焰贴图。
- M02：壁挂旗由四点平面改成 8×16 分段，旗顶固定，旗尾不同高度的波浪有相位差。草丛沿用共享世界阵风，增加草梢侧向摆动与小幅前后扰动，根部权重保持为零。
- M03：塔、抑制器与基地彩色核心持续呼吸；光带沿晶面高度移动；相位随世界位置不同。红蓝都处理，塔身和底座不位移，保留攻击蓄能。
- M04：壁灯只对暖色灯玻璃明暗变化，墙面暖光起伏；冰晶采用晶面光带。石质小物件保持稳定。

动态时间直接来自比赛模拟时钟，无 `setInterval`、独立 RAF 或累计动画偏移。暂停停表、重开恢复。所有材质 hook 继续链接团队色、环境材质与既有着色器。

性能边界：无新增图片、纹理、渲染目标或绘制批次。7 面旗帜共增加约 1043 顶点、1778 三角形，仍保留材质合批；其他主要代价是少量顶点/片元三角函数。未新增每帧建筑影图更新；草叶动态阴影精确匹配仍未纳入本轮交付。

## 验证

[浏览器报告](report.json)逐类隔离，比较模拟时间 2 秒与 2.35 秒；七组（含红蓝建筑）都有可测运动，重复 2.35 秒时均无像素差。它证明时钟生效和暂停稳定，感知改善仍需连续播放及试玩判断。

旗帜、壁灯的验收镜头位于桥内靠墙处（u=-357、v=-60），没有放大物件或提高缩放；它们不在所有桥中央镜头内。两组全场景序列保留真实遮挡，隔离像素统计不能替代全场景的可见性。

- 全量 141 个测试文件、784 项通过；使用 `--testTimeout=15000` 容纳已有长时兵线模拟，未调整项目超时配置。
- TypeScript 与 Vite 生产构建通过。
- 五次重开均为 137 个几何、33 张纹理，未递增。
- [战斗与真实输入回归](combat/browser-report.json)通过，音频实际输出、暂停和五次重开正常，错误数组为空。
- 浏览器 shader 编译无错误，场景动态验证失败数组为空。

复现：开发服务 5173 启动后执行 `node scripts/validate-three-scene-motion.mjs`；战斗脚本顺序运行，避免热更新干扰验证页面。

## 后续顺序

1. M05：建筑贴图内的挂旗和附属挂件拆分。塔上挂旗目前仍静态，不能与已完成的壁挂旗混淆。
2. M06：路边低矮风卷雪与桥下空气流动，复用已有预算，保证对线可读性。
3. M07：草丛接触扰动、踩雪和雪粉响应，先核实已有实现，不改变战斗规则。

集中参数在 `EnvironmentMotion.ts`；火和水晶 hook 在 `MaterialAccents.ts`；各物件模块负责自己的时间 uniform。后续不重新建立重复计划，也不将静态主体全体摇动当作场景动画。
