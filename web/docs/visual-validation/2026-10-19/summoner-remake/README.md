# 破盾、Q3 蓄风、闪现、点燃重制

当前 Three.js 入口：`/three.html?map=howling&scene=combat`，正式对线 `scene=match`。本轮替换的是当前 Three.js 实机展示；保留的 Phaser 旧入口仍使用原有贴图特效。音频层两个入口共用。

实机差异：原 Q3 是高耸蓝焰，改为绕身体前后的低饱和青白风带；护盾改为细蓝色壳与旋转风痕，耗尽和自然结束都有 300ms 外散碎风；闪现为起终点独立的短金色闪光、柔光和火星，320ms 结束，不连接位移路径；点燃为贴着目标腰腿的独立橙色火舌和上升火星，跟随移动和击飞，到期/死亡消失。

视觉采用原生路径和可复用几何批次，依照项目已有原版演示及实机尺度重新绘制；不是原版客户端粒子系统的逐像素复刻。本轮没有新增 AI 位图任务。声音直接取自用户本机客户端的真实闪现和点燃事件，见 `assets/audio/summoners-client-v2/README.md`。

同时修复 `CombatInk` 双面绘制：之前 camera-facing 条带的背面会被剔除，导致部分线条不可见。保留同时进行的战争迷雾可见性过滤。

验证资料：

- `before/`：修改前生产模块实机截图。
- `review/`：新版蓄风、护盾、破盾、闪现、点燃及结束截图；`report.json` 记录声音完整播放、采样能量、到期释放与页面错误。
- `final/`：通用战斗回归，涵盖 Q/W/Q3/EQ3/R、召唤师技能、暂停、五次重开和资源稳定性；在最终柔光细调前执行。
- `scripts/validate-summoner-remake.mjs`：最终特效和音频浏览器验收，可重新运行。
- `tests/summoner-remake.test.ts`：闪现去重、暂停恢复、静音后台、目标死亡/到期清理、风带前后层与线条可见性回归。

程序音频验证确认 MP3 可解码、非静音、未削波，浏览器跑完一个完整持续音周期并在技能结束后归零；音色接近程度仍以实际试听为准。

最终检查：`npm run build` 通过；`npm test -- --maxWorkers=2 --reporter=dot` 为 146 个文件、804 项测试全部通过。默认高并行执行曾有一次既有兵线测试触发 5 秒超时，该测试独立复查和限制并行后的全量执行均通过，未修改测试超时或兵线逻辑。最终浏览器专项检查无页面错误，点燃结束后音频 RMS 为 0。
