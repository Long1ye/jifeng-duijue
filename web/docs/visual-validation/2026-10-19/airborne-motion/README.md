# 击飞动作自然度优化

旧逻辑只使用剩余控制时间计算高度，碰撞时立即跳到最高点，悬停至最后 180ms 再匀速下降。目标姿态继续取普通动作，因此容易呈现整张站立贴图被搬起的僵硬感。

本轮添加仅供表现使用的击飞起始时间和受力方向：前 160ms 快速但连续地上升，短暂过顶后在最后 580ms 内逐渐加速回落。英雄和小兵均按自身身高缩放。增加以躯干为中心的轻微后仰、上升拉伸和小幅受力偏移；落地后 180ms 内作脚底固定的轻微压缩回弹，立即允许正常游戏操作。原有受击平移在腾空中不再叠加，避免双重冲击。

空中的英雄使用不含攻击、施法或吹箫的显示状态，避免播放尚未清理的旧出手动作；这些处理只作用于渲染副本，不改写实际技能状态。身体、血条、风流与阴影使用一致的高度曲线。碰撞坐标、伤害、击飞控制结束时间和接 R 条件保持原值。

Q3、EQ3 均记录准确的起始时间和方向；R 延长滞空时保存衔接前的曲线高度，在 120ms 内平顺地接入悬停，不重播起飞。死亡清理击飞姿态数据。仅有 `airborneUntil` 的旧练习设置继续兼容原有悬空显示。
