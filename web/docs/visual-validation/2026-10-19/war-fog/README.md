# 战争迷雾第一版

[查看场景对照](http://127.0.0.1:5173/docs/visual-validation/2026-10-19/war-fog/comparison.html) · [进入正常比赛](http://127.0.0.1:5173/three.html?map=howling&scene=match)

正常比赛默认开启。「选项 / 练习」中的「战争迷雾」按钮可关闭对照；美术查看、灰盒和固定靶场保持原全亮方式。基地与友方建筑附近开始时清晰，向前推进或移镜头到敌方区域可看到迷雾。

## 观感与行为

- 当前可见区域保留原画面；无视野区域压成冷暗蓝灰，保留道路、建筑和装饰轮廓。走过后失去视野，地形恢复为稍浅的暗色记忆，不保留敌人本体或位置标记。
- 视野在世界空间由友方活英雄、小兵、防御塔及基地内现有静态友方建筑共享。当前只有外塔有完整可破坏模拟，死亡外塔不供视野；内部装饰塔/出生区仍供固定视野。
- 草丛依据真实地面范围，外部来源不能直接揭示草内敌人；同片草内友方可揭示。敌方攻击/命中友方后短时暴露 1.5 秒。参考 [Riot 13.22 关于雾中攻击暴露的说明](https://www.leagueoflegends.com/en-us/news/game-updates/patch-13-22-notes/)，本项目未宣称数值或完整例外与原版完全一致。
- 移动镜头、缩放和暂停不创建视野。边缘做空间羽化与基于比赛时钟的渐变，只有边界有轻微流动。
- 敌人无视野时，本体、动作地影、血条、E 目标计时环及点击代理一起移除；选中读数清除，玩家追踪攻击停止。指向 E/R 需要可见目标。来自不可见位置的敌方事件/声音过滤；友方投射物保留。
- 地图建筑仍可辨；敌方外塔仅在有视野时更新完好/摧毁信息，雾中不泄露隐藏血量与蓄能。景观动画继续使用既有时钟。

## 第一版边界

这是玩家展示/输入视野版。原 Match 的双方 AI 目标搜索和伤害模拟保留，尚未把视野接入双方 AI 或服务器权威规则；不作为完整原版战争迷雾交付。未加入眼位、真视、隐形单位检测、地形射线遮挡、小地图迷雾或隐形例外。草丛矩形范围采用现有美术布局。后续扩展应首先统一模拟层视野权限。

## 参数与成本

`TeamVision.ts`：英雄半径 360、小兵 240、塔 430，柔边 52，短时暴露 1.5 秒，数值均为本项目世界单位；基地内静态建筑半径 420。判断与相机无关。

`WarFog.ts`：512×288 RGBA 场，R 为平滑当前视野、G 为已见地形；仅在视野源周围栅格写入。后续[草丛颜色修正](../war-fog-brush/README.md)移除了草丛格过滤，草叶颜色与敌人隐藏分开处理。相同模拟时间/来源跳过更新。源地图和原材质不改写。

通过带深度纹理的离屏场景和一次全屏合成应用迷雾。保留最多 4× MSAA，重建实际建筑/地形世界坐标；桥下背景使用地面投影，DOM HUD 保持独立。场景只绘制一次，另加全屏合成、颜色/深度目标和视野纹理。成本随内部画面分辨率变化，不外推为全设备帧率保证。

## 验证

[专项报告](report.json)：六项均通过，无浏览器/shader 错误：

1. 视野外敌人本体、血条与点击代理均不可见/不可选。
2. 友方小兵前移后敌人出现。
3. 失去来源后敌人及血条消失。
4. 暂停时移镜头，视野来源和视野纹理完全不变。
5. 在实际作者草丛内的敌人从草外不可见。
6. 友方进入同一片草后敌人出现。

明区采样与关闭迷雾的直接绘制相比，平均通道差 0.435/255、最大 2/255。五次重开均为 97 个几何、38 张纹理，未递增。对照使用真实 Match，验证脚本中重排单位/禁用 AI 仅为确定性复现，正式比赛没有这些调试操作。

全量 146 个测试文件、804 项通过（`--maxWorkers=2 --testTimeout=30000`）；TypeScript / Vite 构建通过。实际菜单开/关/开与预览加载通过。[成熟战斗/音频回归](combat/browser-report.json)保留专项结果；战斗回归使用固定靶全亮方式，视野过滤另由上述专项和 TeamVision 单测覆盖。

复现：开发服务 5173 下执行 `node scripts/validate-three-war-fog.mjs`。入口为 `ThreeArena.fogEnabled`；关闭只绕过显示/输入视野，不释放后重建资源，比赛重开清除探索和暴露记忆。
