# 五处截图反馈修复

[打开对应位置动态预览](http://127.0.0.1:5173/docs/visual-validation/2026-10-19/motion-feedback/motion.html)：可选择墙上火焰、蓝晶体、红晶体、塔旗和火盆遮挡，并切换正常视野/局部原比例裁切。所有截图在固定 45°、正常缩放 0.6、1600×900 下采集；局部图仅裁切中心 480×360，不放大资产。16 帧、8 张/秒用于查看变化，不是游戏帧率录像。旧 motion / motion-v2 页面是历史记录，不会自动更新为本次代码。

## 对应反馈与根因

| 截图 | 原因 | 修复 |
| --- | --- | --- |
| 墙上三处火 | 与独立地面火盆不同，火焰烘在圣所背墙原图里，未接动画 | 按原图三处坐标限制 UV 扰动和火内亮度流动，仅对暖色火焰像素处理；保留墙、盆体和柱像 |
| 蓝晶体暗 | 原乘色 `0xc6d4e2` 加上动画最低 0.68 倍进一步压暗 | 地上/墙顶晶体恢复白乘色，动画只增强受光；桥下冰挂保留原暗色环境 |
| 红晶体变蓝 | 动态受光在阵营换色之前运行；浅蓝晶面未完整换色，且缓存键未明确区分塔的红蓝着色程序 | 换色先于动态受光，扩大冰晶专用浅蓝遮罩，按材质阵营锁定反光色；红蓝程序缓存键分开，雪面低饱和区保留 |
| 右侧塔旗不动 | UV 掩码下缘 .47～.50 排除了实际旗尾约 .40～.47 的区域 | 两侧旗帜尾部范围修正为 .385～.405，杆端固定，旗尾加强侧摆；复用既有分段网格 |
| 火盆火焰穿插木炭 | 火焰面朝相机倾斜、上端后退，但原盆图是竖直 relief，造成深度交叉 | 改为竖直面并补偿 45° 投影高度；保持火根原位置，整张火焰面深度一致，前盆沿/木炭按实际深度遮挡 |

未修改原图文件、地图位置、碰撞、伤害、技能时序或音效。新增墙上火焰效果沿用原材质和比赛模拟时间，不增加绘制批次或纹理。现有物件的资源释放方式保持一致。

## 专项验证

[报告](report.json)在同一固定镜头内隔离相关源物件，所有检查通过、浏览器错误为空。

- 塔旗局部区域在 2 与 2.35 秒之间有 **559 个轮廓像素**变化，证明旗尾形状移动，不只统计颜色变化。
- 红晶体在 0～2.75 秒的 12 个时刻均有 1693～1717 个红色像素、0 个蓝色像素；统计使用亮度与饱和度阈值，排除黑底和中性雪，不声称每个像素都必须纯红。
- 仅切换旧乘色与白乘色、其他动画时间相同：隔离蓝晶体平均屏幕亮度由 125.25 升至 150.32，约提高 20%。这是该采样物件的乘色对照，不是全场景亮度或视觉感知保证。
- 墙上火、蓝晶体、红晶体、塔旗、火盆均有可测时间变化；重复同一模拟时间时，变化超过 2/255 的像素均为 0。
- 五次重开均为 140 个几何、34 张纹理，无持续增长。
- 143 个测试文件、793 项通过，使用 `--maxWorkers=2 --testTimeout=30000` 容纳既有长时兵线模拟；生产构建通过。
- [战斗/音频回归](combat/browser-report.json)保存本次输入、技能、声音、暂停与重开结果。

火盆遮挡通过竖直面测试及正常视野/原比例裁切检查。上述技术指标不替代试玩对真实感和美术风格的判断。
