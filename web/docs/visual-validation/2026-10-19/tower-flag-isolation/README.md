# 塔旗带动塔身扭曲修复

2026-10-19。用户截图指出塔旗摆动时塔身被拉扯。根因是 `MaterialAccents.ts` 的旗布 UV 遮罩覆盖到了侧面石墙，且相邻网格三角形会插值传播位移。加大幅度后此问题更明显。

已将左右旗布遮罩边界分别固定到原 32 列网格的 0.21875、0.8125 列边界，并在内侧整列归零，避免石墙所在三角形获得旗布位移。顶部旗杆和下方台阶范围固定；保留旗布较大的摆幅。新缓存键确保更新程序。独立的 `towerFlagTime` 仍引用同一个比赛时钟，只供验证时冻结其他材质变化。水晶的发光、悬浮和墙挂旗不改。

[蓝红塔旗连续近景](preview.html)：正常 ThreeArena 的塔模型和材质，固定 45°、缩放 0.95，16 张连续采样循环、8 张/秒，不作帧率基准。为了隔离变形，预览只显示塔，冻结水晶发光及悬浮，实际游戏继续保留它们。

验证命令：`node scripts/validate-tower-flag-isolation.mjs`。对蓝、红两塔各检查 24 个时刻，仅推进旗布时钟；塔身中央和两侧内缘的固定矩形区域变化为 0，区域外旗布均有明显变化，暂停重复渲染差异为 0。具体范围见 [report.json](report.json)；该区域检查不等于全画面没有颜色变化。errors/failures 为空，已查看近景截帧。3 文件 8 项专项测试及生产构建通过。未重复运行全量或战斗回归。
