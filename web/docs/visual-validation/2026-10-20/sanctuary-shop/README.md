# 圣所商店入口

保留现有圣所 / 水晶建筑，在蓝红双方出生区域旁各加入一座覆雪武器摊位。包括酒红色棚顶、剑形木招牌、暖灯、武器架、药瓶、货箱；摆设只参与呈现，不改地形碰撞或泉水购买半径。

正常 Three.js 对局中，左键点击己方圣所主体、摊位的可见部分，或“圣所商店”招牌，打开现有装备商店。P 与 HUD 金币入口保留。可随时浏览，实际交易仍需位于己方泉水并处于对局中。联机入口跟随当前玩家队伍，敌方圣所不会打开商店。

圣所和摊位使用射线与贴图 alpha 联合拾取，透明角落留给地面操作；实体选中、技能确认及 A 攻击选点优先。只有低于现有拖动阈值的左键点击才打开商店，右键移动和拖动镜头保持原流程。招牌跟随世界位置与镜头缩放，离屏时隐藏，可用键盘聚焦。

素材由 game-assets 通用生成 Image2.5 / 极致 / 1K 制作，任务 `job_4b180f8a4982479ca4fc311f3033e3f2`，费用 10 积分。运行时 PNG 为 1024×1024 RGBA，已检查透明背景及贴图边缘。下载曾遇到 Windows 长路径问题；使用完整新版 runner 轮询原任务，并改为短下载路径恢复，没有重复生成或扣费。最终素材位于 `assets/map-modules/sanctuary-shop-2026-10-20/runtime/shop.png`。

验证脚本 `.cache/check-sanctuary-shop.mjs` 在真实浏览器验证：招牌打开商店、圣所主体打开商店、买入多兰之刃、Esc 关闭、从圣所拖动地图不会打开商店、红方自己的招牌正确显示；无浏览器运行错误。`sanctuary.png` 为蓝方正常开局实机图；`red-sanctuary.png` 为切换本地队伍与镜头后的红方显示检查。

`npm run build` 通过；地图拖动、目标拾取、场景生命周期、装备经济、双人装备同步与加载门禁相关 6 个测试文件、41 项测试全部通过。
