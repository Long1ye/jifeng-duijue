# 装备系统 · 2026-10-20

正常单人、联机与原版入口接入六格装备、金币、泉水购买 / 出售、递归组件抵扣、合成树、推荐与属性筛选、搜索。按 P 打开 / 关闭，Esc 关闭，选择装备后购买或双击购买，点击已穿戴装备查看与出售。打开商店不暂停战斗；商店内键盘输入不会释放技能。固定靶场不启用装备经济。

## 数据与范围

首批 16 件：长剑、短剑、鞋子、多兰之刃、灵巧披风、十字镐、暴风之剑、吸血鬼节杖、反曲之弓、狂热、红水晶、布甲、狂战士胫甲、无尽之刃、幻影之舞、破败王者之刃。

装备名称、价格、出售价格、基础属性及配方来自 [Riot DDragon 16.20.1](https://ddragon.leagueoflegends.com/cdn/16.20.1/data/zh_CN/item.json)，原始数据保存在 `docs/item-data/items-16.20.1.json`，选定条目保存在 `docs/item-data/selected-16.20.1.json`。DDragon 使用方式见 [Riot 开发文档](https://developer.riotgames.com/docs/lol#data-dragon)。运行时不联网取数。

属性由等级基础值与装备重新计算，避免重复加成或升级丢失装备。攻速上限 2.5，移速采用 415 / 490 软上限。暴击沿用项目亚索规则：翻倍，超过 100% 的每个百分点转 0.5 攻击力；溢出显示在 HUD 并计入普攻、Q、E、R。普通暴击沿用既有 1.9 倍伤害，无尽增加 0.3 × 0.95 倍；装备攻击特效不暴击。

生命偷取使用实际扣血量，不能从护盾、建筑或过量伤害中获得额外回复。多兰全能吸血的范围伤害按三分之一回复，点燃不触发；点燃的重伤同时影响装备治疗。反曲之弓同名被动不叠加。Q / Q3 / EQ 的装备攻击特效和生命偷取只作用于每次施法的首个目标；Q3 用独立弹体标识去重，避免后续 Q 干扰。

幻影之舞忽略英雄和小兵碰撞，建筑与地形仍阻挡。破败为本项目适配：当前生命 8% 的物理攻击特效，小兵上限 60；对同一英雄 6 秒内命中三次减速 30% 持续 1 秒，触发后冷却 15 秒。这些数值明确显示在商店，不声称完整复刻端游全部交互。

开局 500 金币；110 秒后自然收入 2.04 / 秒。补刀近战兵 21 + 每 90 秒 0.125，远程兵 14。英雄击杀 400，塔击杀 250，有镀层的地图每层 125（冰桥无镀层）。经济为现有 Solo 适配，未引入 ARAM 的被动经验、金币或伤害修正。AI 在泉水按相同价格购买，多兰 → 攻速鞋 → 破败 / 无尽 / 幻影之舞。

装备唯一限制、金币、泉水距离和栏位均在纯模拟层检查。网络只提交装备 ID 或出售栏位，服务器按 socket 所属队伍裁定，不接受客户端价格 / 金币 / 属性。协议版本升级为 5，已有联机服务需重启，双方刷新后重新加入。新局自然重置所有装备经济状态。
