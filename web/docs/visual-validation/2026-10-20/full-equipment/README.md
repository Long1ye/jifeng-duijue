## 交互与结算

Three.js 和 Phaser 均支持 P / 金币 / 圣所打开商店、搜索、属性与地图筛选、原版说明、Solo 实现说明、配方、购买合成出售。保留六个装备位，增加独立饰品位。右键装备或 `1/2/5/6/7/8` 使用对应主动，`4` 使用饰品；详情页也有使用按钮。3 仍为吹箫。商店不会暂停战斗，文本输入期间不触发战斗快捷键。

属性覆盖攻击、防御、AP、魔抗、急速、穿透、回复等；亚索仍使用剑意，不消耗法力。主动包括药水、合剂、金身、净化、九头蛇、移速、减速、护盾、治疗、火箭腰带、海克斯科技枪刃、饰品及冰桥锚点等。被动接入混合攻击特效、咒刃、重伤、灼烧、顺劈、护盾、救主灵刃、复活甲、死亡之舞延迟伤害、装备成长等多类效果。

上述为 Solo 适配，不宣称精确还原全部端游装备脚本；商店区分官方文本和实际适配说明。部分效果采用项目数值，队友专属效果在 1v1 中无目标，法力消耗效果不会由亚索触发，任务奖励和英雄专属装备仅供查看。当前没有撤销交易和跨局存档，普通消耗品每件占一格。原有 Solo 经济与胜利规则保持一致。

纯模拟层校验金币、商店距离、地图、条件、唯一组与栏位；服务器按 socket 所属队伍执行购买、出售与主动使用。主动冷却、护盾、药水、复活、饰品和装备状态纳入权威快照。协议版本 6，旧联机服务须重启，双方刷新重新加入。
