# 中央桥段：真实三维结构样板

2026-10-16。用户明确要求消除围栏、桥柱的贴图感，并提出整个环境以3D搭建。本轮将中央围栏、桥拱和支撑改成真实体积，替代整张建筑立面贴片。环境转向3D、像素角色继续复用；目前是中央样板，不是整张地图已经重建或美术目标已经验收通过。

入口：`http://127.0.0.1:5173/three.html?map=howling`。默认精细精度，保留标准档。俯角45/60/75现在可在三维样板直接切换。地表仍使用原图作表面材质；这与用一张图片代替建筑轮廓不同。

## 已改为实体的内容

- `CentralBridgeStructure.ts`负责真实几何：厚低墙、柱体、基座、压顶、倒角、双面浮雕、冰晶和冰挂；遮挡淡出局限于前景对应墙段。
- 桥拱使用闭合挤出几何，厚40，倒角2；开口贯通，具有拱顶内壁。径向拱石有独立轮廓，桥墩与扶壁延伸至地面下380；桥面边带和柱顶共用世界锚点。整张栏墙/桥拱PNG不再参与中央结构渲染。
- 雪盖与桥肩积雪使用实体低多边形体积；地面薄霜/雪边保留表面覆盖材质。
- 火盆使用石座、碗形盆、口沿与实体火焰；原整张火盆广告牌退出中央渲染。
- 深渊石柱使用有侧面、雪顶和真实位置的三维几何，随相机产生视差；原整张背景图退出中央渲染。当前远景仍为简化柱状结构，需要继续雕琢轮廓和层次。
- 地面材质接入实际光照、凹凸和阴影，桥面本体继续使用实体几何。现有源贴图不是规范化高度图，凹凸只作微弱表面起伏，不当作精确石缝高度。
- 中央刻纹仅出现一次。两端增加外缘石面的镜像过渡，共延伸到u[-172,164]，没有重复中央地标、没有扩大模拟地图或改碰撞。两端过渡仍存在可辨认的镜像母题，不声明已完成无缝全图地表。

结构材质使用已有64×64石砖表面纹理。源地表及雪边PNG保留，不改写；不调用生成服务、不消耗积分。当前结构的造型细节和材质密度仍低于已认可目标图，尤其是兽像、大型装饰柱、破损变体和自然积雪，后续应在实体模型上继续制作。
