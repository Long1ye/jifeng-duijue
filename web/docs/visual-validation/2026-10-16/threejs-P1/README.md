## 入口与范围

- 开发：启动 `npm run dev`，路径 `/three.html?map=howling`。
- 普通生产构建输出 `dist/three.html`，由 `npm run preview` 提供相同路径。
- 原版 `/` 与 `/?map=howling` 入口继续使用 Phaser，未修改原入口源码；无两个渲染器同时更新同一比赛。
- 分享构建仍只发布原默认游戏入口，不把 P1 实验页面设为线上默认。
- Three.js 固定版本 `0.186.1`，类型 `@types/three 0.186.0`，锁文件已更新。

P1 覆盖完整逻辑桥面的诊断几何和 S01 样板区域标色、建筑占地占位、阵营与朝向灰盒、投射物/风墙/Q 诊断线、目标选择、右键移动/攻击、Q/W/E/R 模拟命令、固定靶/正常对局、重开/暂停、跟随/自由平移/缩放、俯角候选和纹理密度候选。范围圈显示真实逻辑 Q 半径。R 仍需满足真实击飞条件，不绕过模拟规则。

## 工程决策

| 事项 | 当前实现与原因 |
| --- | --- |
| 启动隔离 | 独立 `three.html` / `main-three.ts`，保留旧 main.ts 和 Phaser，避免扩大既有 UI 耦合；暂不实现 renderer 查询参数 |
| 坐标 | 逻辑 `(x,y)` → `(x-3100,height,y-1700)`；平面等距，不再应用布局 u/v 的斜投影；视觉高度不改变逻辑距离 |
| 相机 | 固定方位正交相机，俯角45/60/75候选，初始60；基准高度270、缩放0.6/1/1.5，与容器宽高比适配 |
| 拾取 | 客户区像素减去画布 DOM 边界 → NDC → 真实正交相机射线 → Y=0平面 → 逻辑坐标；不依赖屏幕缩放猜位置 |
| 目标 | 仅战斗实体灰盒参与目标射线；地表、底座与诊断线不抢占命令；施法瞄准实体时使用其逻辑位置 |
| 地图 | 从既有 Bridge 轮廓与占地构建，不引入另一份碰撞；32世界单位网格实例化，32/64仅切换诊断纹素密度 |
| 宿主 | PrototypeHost 固定60Hz、最大0.25秒帧积累、呈现插值、单次事件消费、暂停/重开/释放；视图不结算伤害 |
| 资源 | 退出/HMR取消 rAF、监听及 ResizeObserver，释放实例缓冲、几何、材质、纹理与 renderer；连续重开 GPU 稳定性仍需浏览器实测 |
