# P2 S01 地表02：嚎哭深渊多地表与自然过渡

日期：2026-10-16。状态：代码与素材接入完成，实机画面、GPU编译、性能与用户风格验收待补。仍处于P2，不进入P3全图生产。入口：`/three.html?map=howling`。

## 目标与主题

根据用户确认，主题始终是嚎哭深渊；Eldest Souls和Hunt the Night提供像素画风、石质层次与氛围参考。页面名称从“灰烬石桥”改为“嚎哭深渊 · 冰桥”，以免视觉方向误解为另一张暗黑遗迹地图。

样板仍是蓝方外塔至中央桥段。详细地表范围为桥局部坐标u[-280,80]、v[-104,104]；外围至栏墙保留原结构。现有地图轮廓、碰撞、通行高度、战斗和角色动画不变。

## 地表设计

| 区域 / 元素 | 实现 | 需要实机确认 |
| --- | --- | --- |
| 主路大石板 | 错缝铺装、八边缺角轮廓、独立明度、少量裂纹/磨边/矿物斑；暗色接缝床，替代S01内原单一64单位重复地砖的表面 | 是否仍过于程序化、砖缝是否过密、近远景纹素密度 |
| 局部修补带 | 两处手动定位的深色小砖区，破碎边缘；与大石板尺寸和排布不同 | 区域是否自然、与主路明暗关系及是否误认碰撞 |
| 外塔地面 | 放射扇形铺装、残损外环及少量冰蓝嵌线，从塔脚延伸到周边 | 塔基是否融入地面，环形线是否太规则 |
| 中央桥段 | 独立铺装和残损环，尖角寒霜刻纹；保持其余战斗地面安静 | 主题辨识、技能范围与刻纹是否混淆 |
| 积雪与薄冰 | 沿正v桥肩的连续起伏边界，薄冰边缘→碎霜→积雪核心；以像素阶梯轮廓连接，而非随机方块换图 | 是否像自然积雪，融化边缘、重复冰纹和亮度是否合适 |
| 冻苔 / 地衣 | 负v背风侧窄带，收敛原有苔藓斑块与草量，正v雪侧不放绿草 | 是否符合寒冷主题，避免森林化 |
| 破损露底 | 两处浅层缺失铺装、残边、石屑；没有视觉深坑或新增地形碰撞 | 层级是否可读且不误导走位 |

主路|v|≤40不放积雪/冻苔覆盖，保持角色和技能可读。新增地表最高0.48世界单位，角色贴片脚底与接触阴影分别调整到0.7/0.65，避免埋入覆盖层。拾取仍使用原逻辑地面。

## game-assets使用与效果审查

新增3张64×64素材，积分730→670（60）；见[素材记录](../../../../assets/map-modules/arpg-s01-ground-v2/README.md)与[尺寸/透明/哈希检查](assets-validation.log)。所有运行PNG与生成原图字节一致。

两次石材生成都未满足“无砖缝裸石”要求，检查后限定用于小砖修补与露底，没有强行铺进大石板内部。原生图和3×3整数最近邻铺贴已查看，但重复母题仍可见，不宣称生成即合格。真正的裸石材质、更多手工破损变体与完整过渡图集仍有优化空间；本轮是原生几何与有限素材混合方案，不能表述为已经充分发挥素材工具或达到参考游戏品质。

`S01Ground.ts`集中维护区域、铺装、覆盖场与批次；每个表面合并为一个Mesh，共8个不透明地表批次，未增加逐帧地表计算。新增材质使用标准Lambert及小范围map_fragment亮度细节处理，纹理最近邻、无mipmap、64世界单位采样。GPU编译与画面效果尚未获得浏览器证据。
