# 按认可目标图校正中央地图风格

2026-10-16。用户要求以预设美术地图为准，停止参考旧游戏画面。本轮依据[已认可中央桥段](../../../../assets/map-concepts/howling-abyss-target-v1/04-central-bridge.png)调整中央一屏；保持实体3D结构和现有像素角色，不再以“做出了3D体积”作为画风已达标的证据。

## 实际变化

- 移除中央样板对旧64px蓝色石砖的材质引用。按唯一目标图生成新的1024灰紫石材和2048×1536俯视地表，runtime逐字节复制；[来源、原图与校验](../../../../assets/map-modules/howling-target-v2/README.md)。合计19积分。
- 将规整墙体改为逐块错缝石料、残缺上沿与不齐雪边；大兽像柱和较低的冰晶柱交替布置。兽像有实体躯干、前腿、爪、面部、鬃毛、耳与卷尾；柱面和桥墩增加菱形连续石刻。仍是程序雕塑候选，精细度与目标中的兽像有差距。
- 大桥拱保留贯通开口、厚度与底面，补强调色较浅的径向拱石；桥墩上增加雪檐和长短不一的冰挂。
- 雪盖改成不规则薄层几何、零散悬边，减少圆鼓雪团；冰挂变细，长短和密度随位置变化。路肩增加少量碎石和积雪过渡。
- 远景改为有破碎轮廓、侧柱、裂纹、雪顶与冰挂的实体岩柱，配蓝灰雾谷。当前岩壁仍偏规则，尚未达到目标图的自然裂隙与层次密度。
- 中央使用独立实体桥面和专属冷灰灯光，默认俯角45°；60/75°仍可检查转面。中央场景不渲染旧S01环境组；其他标为待重建的测试场景保留独立入口，不作为本轮美术参照。
- 页首对照链接改为认可的美术目标，不再链接旧游戏画面。模拟坐标、碰撞、技能和伤害规则未改。

## 当前边界

色调、石材尺度、柱墙高低关系和标志性部件已按目标图重做。本轮不能宣称已与目标图同等精细：兽像表情和雕刻、石构破损、岩壁自然形态、积雪的细腻过渡仍不足。也没有完成全图、出生区、外塔、性能和完整对局验收。继续完善时仍以认可图为准，不能把旧场景细节重新混入作为快捷补丁。
